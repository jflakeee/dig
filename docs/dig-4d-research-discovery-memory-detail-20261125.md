# DIG 4D 연구·발견 조감도·기억 보존 상세설계

2026-11-25 · 새 물품의 식별 등록, 내장 연구, 영구 발견 기록과 손상된 개인 기억의 분리

**구현 상태(2026-11-26, `next/`).** 메뉴의 연구 패널에서 미지 물질 8종을 종류별로 한 번씩 분석한다. 데이터는 `next/research.js`, 저장은 버전 11이다. 비용·시간은 시험값이다.

- **분석 시작:** 미리 보여준 원소(그램)를 시작할 때 차감한다. 한 번에 하나만 분석한다.
- **분석 진행:** 게임 시간 30–60초가 지나면 시장 시계 기준으로 완료된다. 분석 중에도 채굴과 운행은 멈추지 않는다. 이는 "메뉴를 열어도 운행" 결정을 따른 것으로, 본문 7절의 "분석 중 안전 정지"와 다르다.
- **분석 완료:** 관측 특성과 안전 상태가 연구 기록에 남고, 그 물질의 경매 등록이 열린다. 분석 전에는 경매에 올릴 수 없다.
- **무문자 기억막:** 분석한 뒤 한 장씩 판독한다. 판독한 기억막은 소모되고, 손상된 개인 기억 파편 8개가 순서대로 관측 기록에 남는다. 파편은 작업 기록과 구분되는 별도 스타일(기울임, 보라색)로 잠깐 표시된다.
- **아직 없음:** 연구 트리와 레시피 해금, 광물·포탈 방출물 연구 주제

## 1. 목적

플레이어 기계는 연구·제조 기능을 내장한다. 새 물품을 확인할 때마다 발견 조감도(발견 목록)에 추가하여 플레이어가 지금까지 확인한 물품과 미지 항목을 돌아볼 수 있게 한다. 기계의 개인 기억은 손상되어도, 작업 기록·도감·인벤토리·연구 진행은 정상적으로 보존한다.

연구는 별도 건물이나 매점에서 하지 않는다. 거래는 소형 드론, 연구·분석·제조는 기계 내장 패널에서 수행한다.

## 2. 발견 확인과 조감도 등록

발견 데이터는 청크 생성 시 만들어지지 않는다. 블록 노출·채굴 결과가 확정된 뒤, 플레이어가 센서로 식별하거나 물품을 회수해 확인했을 때 기록한다.

- **미확인 신호:** 미지의 물질/형태로 감지했으나 식별되지 않은 상태. 조감도에는 확정 항목으로 등록하지 않는다. 임시 신호는 현 청크 기록에만 남을 수 있다.
- **확인 완료:** 내장 센서 분석 또는 회수 후 자동 식별로 안정된 discoveryId를 얻은 상태. 즉시 조감도에 새 항목을 추가한다.
- **기등록 항목:** 같은 discoveryId를 다시 발견하면 신규 항목을 만들지 않고 발견 횟수/최근 확인 같은 보조 기록만 갱신한다.
- **변이형:** 외형·재료·용도가 다르거나 서사적으로 별도 식별되는 물품은 별도 ID를 부여한다. 단순 색상·수량 차이는 새 항목으로 복제하지 않는다.

확인 완료는 물품을 팔거나 경매에 등록하기 전에도 가능하다. 미확인 상태의 물품은 시세/제작 용도를 임의로 표시하지 않는다. 식별 비용·시간이 필요한 품목은 미리 요구량을 보여 주고 확정 후에만 소비한다.

## 3. 발견 조감도 화면

조감도는 확인된 물품의 시각적 목록/분류 화면이며, 현재 플레이어 위치나 아직 가보지 않은 청크를 보여주는 월드 지도는 아니다.

항목별 기본 기록:

| 필드 | 표시 목적 |
| --- | --- |
| discoveryId | 종류 중복 방지와 저장 호환 |
| 최초 확인 시각/순서 | 탐험 순서 기록 |
| 표시 이름과 확인 상태 | 미지/가설/분류 완료 구분 |
| 기준 외형 또는 도식 | 나중에 형태를 다시 확인 |
| 분류·사용 용도 | 재료, 제조, 거래 등 확인된 정보만 표시 |
| 관측 단서 | 출처·시간대·기계 흔적 등 아직 확정되지 않은 단서 |
| 발견 횟수/최근 확인 | 재발견 기록 갱신 |

미확인 정보는 숨기거나 “판독되지 않음”으로 표현한다. 미래 지구·진화된 지구 생물이라는 진실을 조감도 초기에 직접 공개하지 않는다. 거래 가격은 시장 견적이므로 도감의 고정 물품 속성으로 저장하지 않는다.

## 4. 내장 연구·분석 흐름

연구는 발견물 식별, 재료 성질 확인, 제조 레시피 해금에 사용한다.

1. 식별/연구 가능한 대상이 있을 때 메뉴에 연구 행동을 표시한다.
2. 대상, 요구 에너지/재료, 예상 확인 정보를 먼저 보여 준다.
3. 플레이어가 확정하면 내장 연구가 실행되고 요구 자원을 한 트랜잭션으로 소비한다.
4. 완료 후 발견 조감도 항목의 확인 상태·속성·제조 용도를 갱신한다.
5. 레시피 해금은 제조 패널에서 보인다. 연구가 자동으로 물품을 제작하거나 인벤토리를 처분하지 않는다.

연구 주제 예시는 광물 분석, 세라믹 가공 조건, 장비 부품 구조, 출구 포탈 방출물의 성분이다. 연구 단계·비용·완료 시간·해금 레시피는 아직 미정이다. 무작위 아이템 결과를 유리하게 바꾸거나 아직 드러나지 않은 청크 내용을 미리 알려주는 연구는 기본 시스템에 넣지 않는다.

## 5. 손상된 개인 기억과 신뢰 가능한 작업 기록

두 데이터 흐름을 분리한다.

- **영구 작업 기록:** 인벤토리, 장비, 연구/도감 해금, 발견 ID, 제조 레시피, 거래 장부 등 게임 진행을 위해 필요한 데이터다. 청크 붕괴와 서사적 기억 손상으로 지우지 않는다.
- **개인 기억 파편:** 기계가 인간의 과거를 기억하려다 잊거나 서로 맞지 않는 장면을 떠올리는 서사 연출이다. 시간 경과 후 사라질 수 있고 반복되지 않도록 관리한다. 조작·수집·연구 결과에 영향을 주지 않는다.

기억 파편은 플레이어가 원하면 별도의 관측 기록 창에서 다시 볼 수 있다. 이 관측 기록은 기계의 개인 기억 자체가 아니라 플레이어를 위한 서사 로그이며, 저장 정책은 개인 기억 상태와 독립적으로 관리한다. 업무 데이터가 정상인데 개인 기억만 흔들리는 점을 통해 AI의 기억 손상을 암시한다.

## 6. 저장·복원·청크 초기화

- 새 조감도 항목, 연구 진행, 영구 레시피 해금은 플레이어 진행 저장에 기록한다.
- 청크별 미확인 신호, 바닥에 남은 물품, 좌표/환경 상태는 청크 임시 기록으로 분리하고 그 청크가 붕괴할 때 초기화한다.
- 확정된 발견 ID와 조감도 기록은 청크 붕괴 후에도 남는다.
- 공유 복원 코드에 조감도/연구를 포함하는 경우 항목 ID와 버전을 검증한 뒤 복원한다. 존재하지 않거나 미래 버전인 항목을 임의로 생성하지 않는다.
- 복원 전에 현재 진행을 클립보드 백업하고, 저장 충돌/복사 취소 시 기존 진행을 보존하는 기존 복원 규칙을 유지한다.
- 개인 기억 연출 상태는 연구/도감/장비 저장 구조와 분리한다. 서사 설정 초기화가 게임 진행 초기화를 뜻하지 않으며, “처음부터 다시 시작”은 확인 후 전체 4D 진행을 별도로 초기화한다.

## 7. UI 규칙

- 새 물품이 처음 확인되면 짧은 “조감도에 기록됨” 알림을 띄운다. 채굴·자동 이동·센서 경고를 가리지 않는다.
- 조감도 버튼은 새 항목이 생겼거나 플레이어가 메뉴에서 기록을 열 때만 노출한다.
- 연구 버튼은 대상과 필요 조건이 충족될 때만 메뉴에 표시한다.
- 분석 중에는 자동 이동/채굴을 안전 정지한다. 완료·취소 후에도 재개 버튼은 안전하게 재개 가능할 때만 표시한다.
- 기억 대사는 낮은 빈도로 표시하고, 연구 결과나 도감 등록 메시지와 다른 시각적 스타일을 쓴다. 설명 대사가 화면을 가리거나 조작을 요구하지 않는다.

## 8. 미정 및 완료 기준

미정: 연구 트리/단계, 식별에 필요한 조건, 에너지·재료·시간 비용, 관측 기록의 보존 범위, 발견 조감도 도식 스타일, 항목 변이 분류.

완료 기준:

- 새 물품은 실제로 식별/확인될 때 한 번 조감도에 등록되고, 반복 발견은 중복 항목을 만들지 않는다.
- 확인되지 않은 청크 콘텐츠는 도감에 노출되지 않는다.
- 연구는 확인된 정보와 레시피만 추가하고, 블록 생성 결과나 거래 가격을 몰래 바꾸지 않는다.
- 개인 기억 손상/소실 연출과 정상적인 장비·도감·연구 진행이 서로 간섭하지 않는다.
- 청크 초기화는 임시 환경 데이터만 지우며 확정된 조감도/연구 진행은 유지한다.
- 복원·중복 입력·저장 실패에도 도감/연구/재료가 부분 적용되거나 중복 소비되지 않는다.
