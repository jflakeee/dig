# DIG 4D 블록 노출·광물·발견물 생성 상세설계

2026-11-25 · 블록을 처음 드러낼 때 광물 또는 발견물을 판정하고, 같은 청크 세션에서 결과를 고정하는 규칙

## 1. 목표

청크를 만들 때 광물이나 아이템을 미리 배치하지 않는다. 플레이어가 암석을 채굴해 새 블록이 처음 드러나 보이는 순간 해당 블록의 내용을 판정한다. 이 규칙으로 미지 공간을 파헤치는 감각을 만들고, 재접속·화면 갱신·반복 채굴로 결과를 다시 뽑는 악용을 막는다.

이 문서는 세계관상 발견 후보와 생성·수집·도감 기록의 처리 계약을 정한다. 모든 블록에서 귀중품이나 아이템이 나온다는 뜻은 아니다. 광물 비율과 희귀 발견 확률은 밸런스 값으로 따로 관리한다.

## 2. 블록 상태와 판정 시점

unexposed → revealed(contentResolved) → mined → collected | leftBehind

- **unexposed:** 아직 채굴 면에서 드러나지 않은 블록. 개별 광물/아이템 결과를 저장하거나 표시하지 않는다.
- **revealed:** 이웃 암석 제거로 블록이 처음 시야에 노출된 상태. 이 시점에 블록의 기본 재질과 추가 발견 결과를 한 번 판정한다. 내용은 채굴 전까지 외형·센서 표식·조감도에 표현할 수 있다.
- **mined:** 블록 제거가 커밋된 상태. 내용은 물리 드롭 또는 인벤토리 보상으로 전환한다.
- **collected:** 플레이어 인벤토리/화물에 들어간 상태.
- **leftBehind:** 청크 바닥에 남은 물품. 같은 세션에서 유지하고 청크 붕괴·초기화 때 함께 소실할 수 있다.

채굴 도중 아직 보이지 않는 블록은 판정하지 않는다. 여러 블록이 한 번에 노출되는 범위 채굴에서는 각 블록을 동일한 규칙으로 독립 판정하되 결과를 한 보상 트랜잭션으로 커밋한다.

## 3. 재현 가능한 무작위 결과

각 블록의 판정 시드는 다음의 안정된 식별자를 사용한다.

rollKey = worldSeed + chunkCoord + chunkEpoch + blockCoord + revealRuleVersion

- 좌표·시드·epoch가 같으면 같은 결과를 재현한다. 화면 렌더링, 카메라 방향, 거래 UI, 저장 재시도는 난수 결과를 바꾸지 않는다.
- 판정 결과를 저장하기 전에 블록 파괴나 보상을 커밋하지 않는다. 저장 실패 시 같은 키로 재시도하여 한 번만 적용한다.
- 청크가 정상 유지되는 동안 저장된 결과를 사용한다. 청크 붕괴로 epoch가 증가하면 그 청크의 암반이 새로 생성되고 새로운 결과를 판정한다.
- 시드 자체는 결과를 재현하기 위한 값이며 플레이어 UI에 노출하지 않는다.

## 4. 결과 계층

블록의 결과는 아래 두 판정을 분리한다.

1. **기본 지질 재질:** 일반 암석, 석탄, 철, 금, 희귀 광물 등. 기본 표의 확정값은 암석 65%, 석탄 18%, 철 10%, 금 5%, 희귀 광물 2%다. 깊이·지역·강화 보정은 사용자가 별도 확정하기 전에는 적용하지 않는다.
2. **추가 발견물:** 지구에서 만들어진 물건, 미래 지구 기술 물질, 외계 생물로 오해되는 잔해, 확인 불가 물체 등. 기본 재질을 대체하지 않는 별도 추가 결과다. 희귀도, 발생 확률, 드롭 수량은 확정되지 않았으므로 콘텐츠 설정값으로 둔다.

추가 발견물의 판정은 재질 결과와 독립적이다. 따라서 암석이면서 작은 발견물을 품을 수 있으나, 발생 확률은 낮게 조정 가능하다. 보석·금속·귀금속을 광물 분류에 포함할지 추가 발견물 분류에 포함할지는 콘텐츠 ID 테이블에서 정하고, 중복 보상하지 않는다.

## 5. 발견 콘텐츠와 세계관 공개

| 발견물 묶음 | 플레이어 초기 인식 | 후속 세계관 진실 |
| --- | --- | --- |
| 지구 유래 물품 | 출처 불명의 유물·폐기물 | 다른 장소 또는 시대의 지구 물품 |
| 미래 기술 물질 | 외계 금속·합성 물질 | 미래 지구에서 개발 |
| 생물 흔적·사체 | 외계 생물 잔해 | 우주 환경에 적응한 지구 생물의 후손 |
| 정체 미상 물체 | 판정 불가 물체 | 즉시 설명하지 않고 장기 서사 단서로 보류 |

같은 발견물 ID는 세이브 도감에서 최초 확인 1회만 등록한다. 처음 얻었을 때 이름·외형·간단한 센서 분석을 보여 주고, 진실을 설명하는 서사는 시간대·거래·기억 단서가 쌓일 때 단계적으로 공개한다. 도감 등록은 청크가 초기화되거나 해당 물건을 판매해도 유지한다.

## 6. 보상·드롭 원자성

- 블록 제거, 기본 광물 획득, 추가 발견 드롭, 내구도 비용, 도감 최초 등록은 하나의 채굴 이벤트 ID로 묶는다.
- 같은 이벤트 ID의 재시도는 이전 결과를 돌려주며 아이템·광물·도감 기록을 중복 지급하지 않는다.
- 화물 공간이 부족하면 자동으로 소실시키지 않는다. 기본 광물은 바닥 드롭으로 남겨 재접근 수거를 허용한다. 청크 붕괴 전 경고·정지 흐름은 별도 청크 수명주기 규칙을 따른다.
- 레이저 긴급 채굴과 드릴 채굴은 같은 블록 결과를 사용한다. 도구 종류가 결과 테이블을 다시 굴리지 않는다.
- 출구 포탈 방출은 채굴 보상과 별도 이벤트다. 동일 출구 이벤트 ID로 중복 방출을 방지하며, 방출 확률은 채굴 발견 확률보다 낮게 설정한다.

## 7. 저장 데이터 계약

RevealedBlockContent: blockId, chunkEpoch, contentRuleVersion, baseMaterialId, optional bonusDiscoveryId, status, revealEventId.

DiscoveryCatalogEntry: discoveryId, firstSeenAt, knownClues.

청크의 임시 블록 판정·바닥 드롭은 청크 환경 기록에 속한다. 영구 도감과 획득 기록은 플레이어 진행 저장에 속하며 청크 초기화로 지우지 않는다. 규칙 버전이 바뀌어도 이미 판정한 블록 결과를 다시 계산하지 않는다. 마이그레이션이 필요하면 명시적 데이터 변환을 추가한다.

## 8. UI·연출

- 드러난 블록에 광물 종류를 미리 노출할지는 센서/조명 범위와 함께 결정한다. 기본안은 눈으로 확인 가능한 외형 차이만 표시하고, 미확인 발견물은 채굴·분석 후 도감에 정식 등록한다.
- 최초 발견 순간 짧은 조감도 등록 알림을 표시한다. 채굴을 가리거나 이동 버튼을 덮지 않는다.
- 저장이 완료되기 전에는 획득 연출을 재생 완료로 처리하지 않는다. 오류 시 같은 이벤트를 안전하게 재시도한다.
- 서사적으로 미래 지구라는 정답을 초반 UI에서 직접 설명하지 않는다.

## 9. 미정 밸런스 및 완료 기준

미정: 추가 발견물 확률·희귀도 분포·수량, 후보별 재료 ID와 모델, 센서가 드러내는 정보량, 바닥 드롭 유지 시간, 출구 방출 확률, 분석 비용·보상.

완료 기준:

- 청크 생성만으로 광물/아이템 결과가 미리 생성되지 않는다.
- 처음 드러나는 블록은 한 번만 결과를 얻고, 화면 갱신/저장 재시도 후에도 동일하다.
- 청크 epoch가 바뀌면 새 암반 결과를 만들되 도감과 영구 진행은 유지한다.
- 광물·발견물·도감 등록은 한 채굴 이벤트에서 중복 정산되지 않는다.
- 기본 광물 비율과 추가 발견물 확률은 서로 다른 설정으로 조정한다.
- 전체 물품 후보는 세계관상 발견 가능 범위를 말하며, 특정 플레이에서 전부 등장하거나 보장한다는 약속이 아니다.
