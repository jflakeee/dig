# 채굴 중 발견하는 장비·미지 물질·생활물품 24종

**구현 상태(2026-11-26, `next/`).** 24종은 `next/finds.js`에 있고, 드릴 채굴 블록의 추가 발견 중 35%를 차지한다(블록당 0.7%, 품목별 같은 가중치, 시험값). 발견물은 블록 작업 키를 개체 ID로 써서 저장한다(저장 버전 7: `finds`, `findLog`, `clockLog`). 메뉴의 보관 물품에서 장비 내구도, 미분석 상태, 시계의 멈춘 시각을 보여준다.
- **장비:** 개체마다 내구도 15–95%를 가진다. 교체형 드릴 헤드는 현재 드릴보다 내구도가 높으면 교체하고, 닳은 헤드는 버린다. 나머지 7종은 메뉴의 보관 물품에서 슬롯 하나에 하나씩 장착·교체·해제한다(`next/equipment.js`, 저장 버전 10). 내구도가 0이 되면 장착된 채로 효과가 멈춘다. 효과(시험값)는 다음과 같다.
  - 보조 드릴: 채굴 간격 0.16 → 0.12초, 주 드릴과 같은 규칙으로 마모
  - 집광 작업등: 중앙 빔이 좁고 멀리 닿음
  - 체인 권취기: 고정 중 기체의 유효 질량 48 → 72
  - 중력 센서 배열: 포탈 표식 감지 거리 32 → 64칸
  - 드론 완충 그리퍼: 압력 격자 캡슐 회수 +2초
  - 밀봉 카트리지: 기체·수은·열기억 결정 포집 +2초
  - 화물 연결기: 화물 열차 구현 전까지 효과 없음
- **미지 물질:** 보관만 한다. 압력 격자 캡슐은 완충 4초, 열기억 결정은 차열 5초 안에 회수해야 한다. 기한을 넘기면 한 번 폭발해 채굴 중인 드릴 내구도가 10 또는 8 줄어든다.
- **생활물품:** 분해기에서 원소로 바로 분해한다. 부품 단계는 아직 없다. 원소 단위(시험값)는 다음과 같다.
  - 선풍기 Cu 2·Fe 3
  - 숟가락: 크롬강 Fe 4·Cr 1, 니켈 함유강 Fe 3·Cr 1·Ni 1
  - 도시락통 Al 3
  - 찻잔 Al 2·Si 2·O 7
  - 유리병 Si 3·O 7·Na 1·Ca 1·Fe 1
  - 시계 Cu 2·Zn 1·Fe 1. 멈춘 시각은 분해 후에도 도감에 남는다.
  - 손수건 C 6·H 10·O 5
  - 이어폰 Cu 1·C 2·H 3·Cl 1
- **거래 (2026-11-26):** 장비·생활물품·지구 물건은 드론에 즉시 판매하고, 미지 물질은 경매에 올린다. [거래 상세설계](dig-4d-trade-implementation-detail-20261125.md) 참고.
- **아직 없음:** 연구·분석, 부품 회수

첫 드릴 장착 뒤 암반을 열면 광물과 함께 다른 시대의 물건이 드러날 수 있다. 같은 화물 공간에 실리더라도 드릴 헤드는 바로 교체할 가치가 있고, 기원을 모르는 물질은 다른 기계가 얼마를 제시할지 지켜볼 가치가 있으며, 깨진 생활용품은 필요한 부품을 얻는 데 쓸 수 있다. 아래 품목과 용도는 첫 콘텐츠 제안이다.

## 1. 매매 가능한 채굴 장비 8종

장비는 개체마다 내구도·강화 단계·호환 슬롯을 보존한다. 드론 견적에서 같은 모델의 구매가와 판매가를 각각 확인한다. 구매하면 화물로 인도하고 플레이어가 장착을 선택한다. 장착 중인 장비를 팔려면 먼저 해제한다. 기체 내장 기본 레이저는 거래 재고와 분리한다.

| 품목 | 장착 위치와 쓸모 | 매매 전 살펴볼 상태 |
| --- | --- | --- |
| 교체형 드릴 헤드 | 전방 드릴축에 장착해 손상된 절삭부를 대체 | 날 마모·호환 축 규격 |
| 보조 드릴 모듈 | 빈 드릴 슬롯에서 추가 굴착 | 모터 내구도·필요 슬롯 |
| 집광 작업등 | 조명 슬롯에서 좁은 범위를 깊게 비춤 | 렌즈 균열·빔 폭 |
| 체인 권취기 | 고정점에서 채굴 체인을 회수 | 체인 마모·지원 하중 |
| 중력 센서 배열 | 센서 슬롯에서 포탈 방향 표식의 흔들림을 줄임 | 보정 상태·감지 범위 |
| 화물 연결기 | 차체 후방에서 다음 화물칸을 연결 | 연결부 손상·호환 차량 길이 |
| 드론 완충 그리퍼 | 드론 팔에 장착해 충격 민감 물체 포집 여유를 늘림 | 완충재 마모·호환 팔 |
| 밀봉 카트리지 모듈 | 드론 수집부에서 민감 시료 보관 용량을 늘림 | 밀폐 상태·남은 용량 |

재고 예시로 내구도 32%의 드릴 헤드와 91%의 같은 모델이 함께 나오면 두 개체를 별도 행으로 보여준다. 견적을 연 뒤 수리하거나 장착 상태가 바뀌면 거래 확정 시 개체 상태와 견적을 다시 검사한다. 완충기·밀봉 모듈을 구하기 전에도 기본 드론의 긴급 수집 버튼은 작동한다.

## 2. 경매 가능한 미지 물질 8종

초기 이름은 센서가 관측한 특징에서 붙인다. 분석하면 안전 상태·관측 특성과 경매 등록 가능 여부가 열린다. 여덟 품목은 최초 카탈로그에서 고정 매매가가 없으며 다른 시간대 채굴기계의 입찰로 가격이 결정된다. 관심 상대는 낙찰을 보장하지 않는다.

| 발견명 | 관측 단서·수집 특성 | 관심을 보일 상대 또는 보관 용도 |
| --- | --- | --- |
| 겹무늬 합금박 | 접힌 자리의 무늬가 잠시 뒤에 따라옴 | 옛 압연 장비를 가진 기계가 표면 패턴을 조회 |
| 잔광 섬유 다발 | 작업등이 지나간 방향대로 빛이 남음 | 광학 장비 수집기 또는 조명 연구 |
| 균열 봉합 세라믹 | 실금이 닫힌 뒤 가는 선 하나가 남음 | 장시간 운행 중인 수리 기계 |
| 역음향 결정 | 드릴 소리가 멎은 틈에 짧은 반향을 냄 | 음향 센서 보정용 표본 |
| 편중력 유리편 | 회전시키면 중력 센서 표식이 잠깐 기움 | 항법 연구 기계가 방향 기록과 함께 입찰 |
| 압력 격자 캡슐 | 겉층에 균열이 번짐. 완충 회수 필요 | 봉인 상태를 보존하면 격자 연구 가능 |
| 열기억 결정 | 작업등 아래에서 내부 띠가 급격히 밝아짐. 차열 격리 필요 | 열 이력 표본을 모으는 제조 기계 |
| 무문자 기억막 | 표면에 해독되지 않는 정렬 자국이 남음 | 연구 시 손상된 기억과 어긋나는 짧은 단서 |

압력 캡슐과 열기억 결정은 [민감 시료 수집 규칙](dig-mineral-catalog-expansion.md#경고를-본-플레이어의-선택)을 공유한다. 봉인에 실패해 소실된 개체는 등록할 수 없다. 등록할 때 실물을 예치하고 유찰 시 동일한 상태로 반환한다. 낙찰 시 등록 기준가의 최대 10배까지 결정하고 낙찰 수수료를 한 번 차감한다. 시세가 없는 물질의 등록 기준가는 드론의 추정 시작가로 보여준다. 세계관상 미래 지구에서 왔다는 사실은 초기 상품 설명에서 숨긴다.

## 3. 분해 가능한 생활물품 8종

같은 이름의 생활용품도 재질이 다를 수 있어 아래에 적은 변형을 각각 식별한다. 분해 화면은 **부품으로 회수**하거나 **그 부품까지 원소로 분해**할 때 얻는 결과를 미리 보여준다. 한 물건을 분해하면 원래 물건은 사라지고 도감의 발견 기록은 남는다.

| 식별한 물품 변형 | 대표 회수 부품·재료 | 분해 미리보기 또는 사용처 |
| --- | --- | --- |
| 구리선이 감긴 탁상 선풍기 | 모터 코일·철제 축 | 코일에서 Cu, 축에서 Fe 회수 |
| 스테인리스 숟가락 | 합금 조각 | 분석된 조성에 따라 Fe·Cr, 니켈 함유 변형이면 Ni도 표시 |
| 알루미늄 도시락통 | 경량 판재 | 화물칸 수리판 또는 Al 회수 |
| 깨진 도자기 찻잔 | 소성된 세라믹 파편 | 세라믹 충전재로 재사용하거나 조성에 따라 Si·Al·O 등 회수 |
| 갈색 유리병 | 착색 유리 조각 | 광학 시험편 또는 분석된 유리 조성에 따른 원소 회수 |
| 기계식 탁상시계 | 황동 기어·강철 스프링 | 기어에서 Cu·Zn 회수. 멈춘 시각은 도감에 보존 |
| 면 손수건 | 셀룰로스 섬유 | 드론 여과재 또는 섬유 성분에서 C·H·O 회수 |
| 고장 난 이어폰 | 피복선·진동판 | 구리 도체는 Cu, 피복과 진동판은 확인된 재질별로 분리 |

예를 들어 탁상시계를 분해한 뒤 황동 기어를 제조에 썼다면 같은 기어를 다시 Cu·Zn으로 바꿀 수 없다. 균열·부식은 남아 있는 부품과 회수량에 반영한다. 첫 분석에서 결과를 고정하고 분해 직전 확인 창에 정확한 게임 수량을 표시한다. 물품 이름만으로 귀금속을 추가 지급하지 않는다.

## 4. 발견부터 처분까지

1. **발견.** 새 블록이 처음 노출될 때 기본 광물을 정하고, 기존 독립 추가 발견 판정이 성공하면 해당 풀에서 후보 하나를 고른다. 이번 24종과 기존 원소 표본·포유물·기타 유물이 이 후보 풀을 공유한다. 드릴·레이저는 같은 결과를 읽는다. 출구에서 떨어진 물품도 같은 품목 정의를 쓰며 방출 빈도는 별도로 관리한다.
2. **식별.** 회수 전에는 외형 단서를, 첫 확인 뒤에는 조감도에 이름과 관측 특성을 표시한다. 장비의 슬롯·내구도, 물질의 봉인 여부, 생활물품의 남은 구성 부품은 각 개체에 귀속된다. 개체 상태가 다른 두 물품을 한 묶음으로 팔거나 분해하지 않는다.
3. **선택.** 장비는 장착 또는 매매, 미지 물질은 연구 또는 경매, 생활물품은 보관 또는 분해가 대표 경로다. 확인된 생활물품에 견적이 있으면 온전한 채 팔 수도 있다. 메뉴에는 현재 가능한 행동을 최대 두 개 표시하고, 민감 시료 경고는 메뉴 위에 표시한다. 자동 채굴과 전진은 계속된다.
4. **정산.** 획득·구매·분해·경매는 개체 ID와 작업 ID로 처리한다. 장착·화물·경매 예치·바닥 드롭 중 실물은 한 곳에만 둔다. 분해와 판매를 동시에 시도하면 먼저 확정된 한 건만 처리한다. 화물 인도가 불가능한 구매는 결제 전 거절하고, 유찰 반환품은 수령 공간이 생길 때까지 주문에 보존한다.
5. **구현 검증.** 중고 드릴을 구매해 잔존 내구도로 장착하기, 캡슐을 봉인해 유찰 후 같은 개체 돌려받기, 시계를 분해한 직후 재접속해 재료와 도감 확인하기를 첫 플레이 검사로 삼는다. 출현 빈도, 매매 기준가, 수수료율, 개체별 분해 수량은 별도 밸런스 값으로 둔다.
