# 지구 물건으로 찾는 원소 118종 · 2026-11-26

채굴 중에는 광물 말고도 지구에서 흘러든 물건이 나온다. 생활용품, 공장 부품, 병원과 연구실 장비 가운데 실제로 각 원소를 담고 있는 사례를 골라 88종을 만들었다. 이 물건들만 분해해도 원소 118종을 모두 얻을 수 있다. 광물과 시료, 미래 원소 캡슐([경로 보완 설계](dig-element-coverage-plan.md))은 그대로 남는 별도 경로다.

질량과 조성은 플레이용 근사값이다. 미량 원소는 실제 제품의 함유량 규모를 따른다. 예를 들어 연기 감지기의 Am-241은 약 0.29 µg이고, 1970년대 원자력 심장박동기의 Pu-238은 약 0.2 g이다. 구현 데이터는 `next/artifacts.js`에 있다.

## 1. 분해기의 숨겨진 설정

> **설정 전용, 게임 화면에 직접 드러내지 않는다.**
>
> 채굴기계의 분해기는 현실의 원리로 물질을 원소로 나누지 않는다. 장치 깊숙한 곳에 아주 작은 포탈이 있어, 넣은 물질을 미지의 세계로 보내고 같은 원소 조성의 순수한 원소로 돌려받는다. 교환할 때마다 미지의 세계가 질량 일부를 수수료로 가져가므로, 분해해서 얻는 원소의 질량은 언제나 넣은 질량보다 적다.
>
> 채굴기계는 분해기가 이렇게 동작한다는 사실을 기억하지 못한다. 기계가 남기는 기록에는 손실량만 있고 원인은 비어 있다. 실제 지구에서 몇 초 만에 붕괴하는 초중원소 원자가 표적 용기에 남아 있다가 분해 후에도 그대로 보관되는 이유도 기록되지 않는다.

**게임에 드러나는 단서**
- 분해 미리보기와 결과에 회수 질량과 함께 `손실 n g (원인 기록 없음)`이 표시된다.
- 손실률은 분해할 때마다 12–28% 사이에서 달라진다. 같은 원료라도 손실률이 일정하지 않다.
- 초중원소는 원자 단위로 회수되고, 이후로도 사라지지 않는다.

이 설정은 [통합 설계의 세계관](DIG_unified_design.md)과 기억 단서 연출([연구·기억 상세](dig-4d-research-discovery-memory-detail-20261125.md))에서 확장할 수 있다. 정체를 직접 설명하는 대사나 문서는 두지 않는다.

## 2. 질량과 손실 규칙

- **원소 인벤토리 (저장 버전 8):** 원소 인벤토리는 그램 단위 실수로 저장한다. 이전 버전의 원소 단위 1은 1 g으로 옮긴다.
- **분해 질량:** 원료 한 개의 질량은 다음과 같다.

  | 원료 | 질량 |
  | --- | ---: |
  | 광물 | 100 g |
  | 광물 시료 | 50 g |
  | 기체 포유물 | 0.5 g |
  | 자연 수은 방울 | 5 g |
  | 미래 원소 캡슐 | 1 mg |
  | 생활물품·지구 물건 | 표의 질량 |
- **원소별 회수량:** 원소마다 `원료 질량 × 원소 질량 비율 × (1 − 손실률)`을 받는다. 광물과 시료의 질량 비율은 화학식과 원자량에서 계산한다. 원자량은 표준 원자량을 쓰고, 인공·방사성 원소는 해당 물건의 동위원소 질량수를 쓴다.
- **손실률:** 손실률은 분해 누적 횟수와 원료 종류로 정한다. 그래서 미리보기와 실제 결과가 항상 같다.
- **원자 단위 처리:** 원자 수가 백만 개보다 적은 양은 정수 원자로 내림한다. 손실 후 원자가 하나도 남지 않는 원소는 회수되지 않는다. 지구 물건 88종은 최대 손실 28%에서도 모든 원소가 최소 한 원자 이상 남도록 정했다. 예를 들어 Og 원자 10개는 7개가 된다.
- **표시 단위:** kg, g, mg, µg, ng, pg 순으로 표시하고, 1 pg 미만은 `원자 n개`로 표시한다.

## 3. 발견 확률

드릴로 채굴한 블록마다 추가 발견 판정을 한다. 발생 확률은 블록당 2%로 이전과 같다. 발생했을 때의 종류는 다음과 같이 나눈다.

| 종류 | 비율 |
| --- | ---: |
| 광물 시료 | 50% |
| 미래 원소 캡슐 | 5% |
| 비광물 발견물 | 45% |

비광물 발견물은 장비·미지 물질·생활물품 24종과 지구 물건 88종에서 고른다. 가중치는 24종이 각 2이고, 지구 물건은 장소별로 다르다.

| 지구 물건 장소 | 가중치 |
| --- | ---: |
| 생활 | 3 |
| 공장 | 2 |
| 의료 | 1.5 |
| 연구 | 1 |

초중원소 합성 표적 용기는 Fm–Og 19종 중 하나를 같은 확률로 담는다.

얻은 것을 모두 분해한다고 보고 30회 모의 실행했다. 118종을 모두 얻을 때까지 채굴 블록은 중앙값 약 6.2만이고, 10–90% 범위는 4.7만–7.7만이다. 지구 물건을 넣기 전에는 약 9.7만이었다. 수치는 모두 시험값이다.
