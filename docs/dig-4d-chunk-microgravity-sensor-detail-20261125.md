# DIG 4D 청크별 무작위 미세중력·센서 상세설계

2026-11-25 · 신규 청크의 미세중력 존재 판정, 물리 적용, 현장 센서 표시 규칙

## 1. 설계 원칙

새 청크는 생성될 때 미세중력장이 존재할지 무작위로 판정한다. 플레이어가 해당 청크에 들어오면 기계의 중력 센서가 현장 미세중력의 존재, 방향, 세기를 표시한다.

미세중력은 포탈 중력과 별개의 월드 특성이다. 포탈이 없는 청크에도 미세중력이 생길 수 있고, 포탈이 있는 청크에도 미세중력이 없을 수 있다. 청크의 미세중력과 포탈 존재/크기 판정은 서로 독립적이다.

## 2. 청크 생성 판정과 고정

청크 생성 요청 시 해당 청크의 미세중력 유무를 한 번 판정한다.

- 청크별 시드는 worldSeed, 정수 청크 좌표, chunkEpoch, gravityRuleVersion으로 만든다.
- 먼저 미세중력 존재 여부를 판정한다. 존재하지 않으면 그 청크의 기본 미세중력 벡터는 0이다.
- 존재하면 방향, 기준 세기, 공간 변화 유형과 편차를 해당 시드에서 추가로 판정한다.
- 저장/세션에서 청크가 유지되는 동안 결과를 고정한다. 렌더 갱신·재접속 복구 시 같은 세션 chunkEpoch의 동일 청크를 다시 굴리지 않는다.
- 청크가 붕괴하고 새 epoch로 다시 만들어질 때에만 새로운 존재·방향·세기를 판정한다.
- 포탈의 소형/대형 독립 생성 판정과 같은 난수 값을 재사용하지 않는다. 미세중력 선택이 포탈 발생 여부를 바꾸지 않는다.

존재 확률, 세기 범위, 공간 유형 비율은 아직 확정하지 않으며 밸런스 설정값으로 둔다.

## 3. 미세중력장 표현과 물리

미세중력은 한 청크 전체가 동시에 균일한 방향으로 잡아당기는 단일 상수가 아니라, 청크별 시드가 정한 약한 가속도장이다.

- 기본형은 청크 내부의 대표 방향과 세기를 가진다. 공간 변화형은 대표값 주위에서 위치별로 방향/세기가 부드럽게 달라진다.
- 힘은 물리 업데이트마다 월드 위치에서 계산한다. 카메라를 중력 방향으로 강제 회전하거나 플레이어 위치를 스냅하지 않는다.
- 미세중력은 플레이어 기계, 먼지, 느슨한 광물/물품, 연결 열차에 유한 가속도로 작용한다. 고정된 암반 블록은 움직이지 않는다.
- 힘과 속도는 정해 둔 상한을 넘지 않으며 관성·충돌·제동을 따른다. 밀도 높은 암반에 끼어 있는 물체를 중력만으로 통과시키지 않는다.
- 인접 청크 경계에서는 두 시드의 값이 갑자기 점프하지 않도록 안전 거리 안에서 부드럽게 보간한다. 존재하지 않는 청크는 0 필드로 취급한다.
- 포탈 근처의 강한 포탈 중력은 별도 장으로 계산하고 미세중력장과 물리적으로 합산한다. 포탈 중력은 포탈 영향권 밖으로 나가면 사라진다.

정확한 가속도, 속도 상한, 보간 구간과 공간 패턴은 기기 물리 검증을 거쳐 설정으로 조정한다. 이 설계는 미세중력을 생존 연료나 자동 이동 명령으로 취급하지 않는다.

## 4. 진입 센서와 정보 표시

센서는 플레이어의 현 위치 청크에 미세중력이 있을 때 현장 상태를 표시한다. 아직 들어가지 않은 먼 청크의 중력장을 공개적으로 지도화하지 않는다.

- 미세중력 없음: 센서에 중립/감지 없음 상태를 표시한다.
- 미세중력 존재: 방향 축(±X/±Y/±Z 성분 또는 합성 방향)과 상대 세기를 표시한다.
- 공간 변화형: 현재 위치의 값으로 갱신하며, 위치가 바뀔 때 자연스럽게 방향/세기가 변한다.
- 경계 통과: 센서는 새 청크 필드가 유효해진 뒤 갱신한다. 청크 생성 중 임시 0값을 미세중력 없음으로 표시하지 않는다.
- 표시 값은 물리값의 측정치이며 임의로 방향을 뒤집거나 존재를 재추첨하지 않는다. UI 갱신 주기와 완충은 시각 안정성을 위한 것이고 물리장을 바꾸지 않는다.
- 포탈 센서 경고는 별도 표식/메시지로 표시한다. 미세중력 감지와 포탈 방향 단서를 한 항목으로 합쳐 오인시키지 않는다.

센서 범위·표시 단위·문구·HUD 위치는 시각 조정값이다. 사용자는 화면 방향과 현재 표시된 버튼만 조작한다는 기본 입력 원칙을 유지한다.

## 5. 저장·복원·청크 초기화

청크별 중력 판정값은 청크 epoch가 유지되는 동안 임시 환경 상태에 속한다. 플레이어 도감·장비·연구 기록에는 미세중력 결과를 영구 해금 정보로 넣지 않는다.

- 같은 활성 세션의 청크 재조회는 동일 필드를 제공한다.
- 현행 4D 규칙처럼 재접속 또는 청크 초기화로 환경을 새로 만들면 기존 위치/필드 연결은 이어지지 않는다.
- 재접속 후 같은 좌표를 다시 생성해도 새 세션/epoch의 새 필드 판정을 허용한다. 이 판정은 월드 시드와 epoch로 재현 가능해야 한다.
- 청크 붕괴는 그 청크에서 움직이던 비영구 물리 객체와 미세중력장을 함께 폐기한다. 장비·인벤토리·도감·연구는 청크 환경과 분리해 보존한다.
- 복원 코드가 환경 상태를 복원하지 않는 경우 미세중력장은 다시 생성하고, 공유되는 영구 진행 상태만 복원한다.

## 6. 성능과 안전

- 현재 플레이어와 인접한 물리 청크만 미세중력 계산을 활성화한다. 먼 청크의 물리 적분이나 센서 HUD 업데이트는 하지 않는다.
- 동일 frame에서 중력장을 한 번 샘플링하고 플레이어/열차/주변 물체별 가속도에 재사용한다. 렌더링과 물리 계산이 중복 가속을 적용하지 않는다.
- 일시정지, 메뉴, 앱 비활성화, 복원, 저장 잠금 중에는 미세중력 이동을 정지하고 표류 속도를 안전하게 처리한다.
- 포탈 전환 중에는 기존 포탈 물리 계약을 따른다. 전체 열차 통과 전 청크 상태를 삭제하지 않는다.
- 값이 NaN/무한대이거나 청크 생성/물리 조회가 실패하면 해당 프레임의 새 가속도를 적용하지 않고 안전 정지/복구 경로를 사용한다.

## 7. 미정 설정과 완료 기준

미정: 미세중력 출현 확률, 가속도/속도 범위, 공간 변화 패턴·비율, 경계 보간 폭, 센서 단위·주사 범위·갱신 속도, 물체별 질량/반응.

완료 기준:

- 포탈과 독립적으로 청크별 미세중력 존재를 무작위 판정한다.
- 같은 활성 청크 epoch 안에서는 결과가 안정적이며 렌더 갱신/재접속 복구 시 재추첨되지 않는다.
- 새 epoch 생성 때만 새 판정을 허용한다.
- 플레이어가 청크에 들어오면 센서가 그 위치의 방향·세기를 표시하고, 미세중력이 없는 청크는 중립 표시한다.
- 물리장은 플레이어/먼지/광물/열차에 유한 가속도를 주되 관성·충돌·제동을 지킨다.
- 인접 청크 경계에서 급격한 가속도 점프나 같은 프레임 중력 중복 적용이 없다.
- 청크 붕괴/복원과 영구 진행 데이터가 서로를 삭제하지 않는다.
