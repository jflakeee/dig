# 포탈 중력과 연쇄 붕괴, 기체 파괴 후 재기동

## 플레이 흐름

포탈이 실제로 열리는 순간 해당 입구와 출구가 속한 각 청크 전체에 중력장이 생긴다. 대기 중에는 힘과 파손 판정을 적용하지 않는다. 입구 쪽 먼지는 빨려 들어가고, 출구 쪽에서는 먼지와 화물이 밀려 나온다. 멀리 있는 블록에도 힘은 작용하지만 모두가 매번 부서지는 것은 아니다. 출구 쪽 암벽이 들뜨고, 떨어진 첫 블록이 다른 블록을 치면 붕괴가 확대될 수 있다. 최악에는 해당 청크의 모든 고체가 이탈할 수 있다.

| 단계 | 판정과 결과 |
| --- | --- |
| 출구 개방 | 청크 전체의 미채굴 고체를 파손 후보로 등록한다. 재질·구속 상태·중력 응력으로 이탈 확률을 정한다. 아무것도 이탈하지 않는 경우도 허용한다. |
| 블록 이탈 | 원래 셀의 고체를 제거하고 같은 질량·조성의 동적 파편을 만든다. 광물과 아이템은 실제 회수 시에만 지급한다. |
| 충돌과 매몰 | 파편·화물과 기체의 질량, 충돌 법선 방향 상대속도, 체인 고정 상태로 밀림을 계산한다. 무거워도 같은 속도로 나란히 이동하면 충격은 없다. 지속 압착은 별도의 틱으로 피해를 누적한다. |
| 강제 통과 | 외력으로 입구 면을 통과하면 일반 통과와 같은 연결을 사용해 새 청크의 짝 출구로 나온다. 자발적 후진 입력 없이도 충돌은 기체를 뒤나 옆으로 밀 수 있다. |
| 도착지 위험 | 도착 청크 생성 시 위험 후보를 정하고 실제 노출 때 성질을 확정한다. 폭발성 광물의 충격 폭발은 순간 피해, 용암 접촉은 접촉 시간에 따른 열 피해를 준다. 센서가 포착하면 경고한다. |
| 생존·사망 | 장착 장비 내구도와 본체 건전성을 구분한다. 장비만 파손되면 수리·긴급 채굴로 이어간다. 본체 건전성이 0이면 해당 운행을 종료하고 암전·순차 점등·기본 레이저의 첫 장면으로 돌아갈 수 있다. |

### 통과 방향

이 설계에서 ‘출구를 지나 새 청크로 간다’는 입구로 밀려 들어간 기체가 새 공간의 출구를 빠져나오는 흐름으로 해석한다. 이미 나온 출구의 뒷면은 역방향 입구로 작동하지 않는다. 도착 직후에도 남은 속도와 현지 중력·파편·위험물 충돌을 처리한다. 소형 개구와 기체 단면이 맞지 않으면 통과 대신 충돌·압착을 처리한다. 열차 이동 시 마지막 차량이 나올 때까지 출발 청크를 유지한다.

### 물리와 저장

- 장의 세기는 거리 따라 달라지되 같은 청크의 어떤 위치도 거리만으로 판정에서 제외하지 않는다. 열린 끝이 여럿이면 각 장과 청크 고유 미세중력을 벡터 합산한다. 시야 거리와 센서 표시 여부는 물리 범위와 독립이다.
- 고정 시뮬레이션 틱에 출구 ID·청크 세대·셀·누적 응력 구간을 키로 추첨한다. 균열 인접 셀과 충격을 받은 셀은 다시 평가한다. 한 렌더 프레임에 처리할 후보 수만 제한하고 대기열을 이어 처리한다. 전체 붕괴 규모를 제한하지 않는다. 먼 파편은 묶어 계산하되 총질량·운동량을 보존하고 기체 주변에서는 충돌체를 분리한다.
- 한 셀에 대해 이탈과 채굴 중 먼저 확정된 사건만 고체를 제거한다. 자연 이탈도 실제 비워진 면의 고체 수와 포탈 예약에는 반영한다. **제안:** 여섯 이웃 동시 생성은 원래 조건대로 마지막 면을 실제 채굴로 비운 경우에만 허용한다. 지형이 모두 파편이 되어도 활성 청크와 기체를 즉시 삭제하지 않는다.
- 전진 추진과 외력 속도를 분리한다. 현재 시험판의 후방 속도 제한은 자발적 추진에만 적용한다. 충격량은 질량과 상대속도로 계산하고 실제 본체 피해는 흡수되지 않은 충격·열량을 기준으로 정한다. 메뉴 개방 중에도 물리와 위험 시계는 진행한다.
- 충돌·폭발·열 피해를 고유 사건 단위로 기록한다. 같은 폭발의 대상별 피해는 한 번만 적용한다. 치명 피해와 운행 종료를 함께 저장하고, 재접속하면 이미 확정된 생존 또는 재기동 상태에서 시작한다. 공식 기록 초기화와 사망 처리는 별도 명령으로 둔다.
### 사망 정산과 재기동

- 사망 당시 소유한 모든 장비는 장착·보관 여부와 관계없이 현재 내구도가 크게 감소한다. 소유권과 장착 정보는 유지한다. 감소량은 기존 잔여 내구도를 넘지 않으며 0인 장비는 파손 상태로 남는다. 정확한 감소율은 밸런스 조정 항목이다.
- 화물은 원래 화물칸의 개체·수량·상태를 그대로 승계한다. 예외는 치명 사건의 충격이나 열 등 실제 원인이 화물에 전달되었고, 해당 화물이 그 원인으로 파괴·용융·기화·유실될 수 있을 때다. 그때만 해당 개체 또는 노출된 수량에 대해 소실을 판정한다.
- 예를 들어 낙석 충돌로 사망하면 충격을 받은 유리병은 깨져 소실될 수 있고, 같은 칸의 충격에 견딘 금속 부품은 남는다. 용암으로 사망하면 열이 전달된 가연성 섬유나 녹아 회수할 수 없어진 물품이 소실될 수 있다. 용암과 차단된 화물칸은 그대로 승계한다. 출구를 통과했다는 사실만으로 손실을 추가하지 않는다.
- 치명 사건 ID에 원인·노출 화물·정산 결과를 연결한다. 이미 충돌로 제거된 화물은 다시 차감하지 않고, 사망 정산·장비 내구도·잔여 화물·재기동 상태를 함께 저장한다. 재접속이나 인트로 재생 때는 확정된 결과를 읽는다. 기존 드릴의 소유권과 손상 상태를 복구하며 첫 드릴을 중복 지급하지 않는다.
- **남은 결정:** 장비 내구도 감소율, 화물별 파괴·열 손실 기준, 재화·도감·연구·경매 주문의 사망 계승 정책.

### 인수 검사

고정 시드로 무이탈·단일 이탈·전량 이탈 세 경우를 재현한다. 먼 모서리에서도 개방 직후 힘이 적용되는지, 같은 속도로 부딪히는 가벼운 물품과 무거운 물품이 기체를 다르게 미는지 검사한다. 이어서 파편에 밀린 기체의 대형 입구 진입 → 짝 출구 이탈 → 용암 접촉 또는 광물 폭발 → 생존·장비 파손·기체 파괴의 세 결과를 분기 검증한다. 치명 피해 직후 새로고침해도 사망이나 손실을 두 번 정산하지 않아야 한다.

사망 검수에는 장착·예비 장비 동시 감손, 충격 취약품과 견고한 화물의 혼재, 용암에 노출된 칸과 보호된 칸, 원인에 맞는 취약품이 하나도 없는 경우의 화물 전량 보존을 포함한다.
