# 청크 여섯 면의 채굴과 지연 포탈 생성


> **2026-11-27 변경:** 아래의 면 정리 조건(마지막 고체 제거 후 대기)과 여섯 면 동시 연결은 폐지했다. 포탈은 새 청크 생성 시 35% 확률로 무작위 면에 예약되어 60–360초 뒤 열린다. 열리기 1분 전부터 센서에 미세중력으로 감지되고 약한 끌림이 커진다. 이 문서의 면 조건 서술은 기록으로만 남긴다.
2026-11-26 통합설계. 일반 굴착으로는 언제든 이웃 청크로 전진한다. 포탈은 면 전체가 비워진 뒤 시간이 지나 열리는 시공간 통로다. 첫 시작 시 전방에는 약한 중력 입구가 하나 보장된다. 이후 생성되는 면 포탈에 아래 규칙을 적용한다.

## 한 면을 비우면

한 변 16m인 청크의 한 면은 0.5m 블록 32×32칸이다. 가운데 통로만 뚫으면 다음 청크로 전진할 수 있지만, 포탈을 만들려면 그 면의 마지막 고체 블록까지 제거해야 한다. 일반 암석도 포함한다. 떠다니는 광물 드롭, 화물, 먼지, 차량은 면의 잔여 블록 수에 포함하지 않는다. 모서리 블록을 제거하면 맞닿은 두 면, 꼭짓점 블록이면 세 면을 함께 갱신한다.

- 한 면이 처음 비워진 게임 시각을 T로 기록한다. 그 면의 포탈은 **T + 300초 + 무작위 추가 지연**에 생성한다. 추가 지연은 양수이며 범위와 분포는 밸런스 시험에서 결정한다. 면별로 한 번 뽑아 해당 청크 세대 동안 유지한다.
- 대기 중에도 다른 면 채굴과 일반 경계 통과는 계속된다. 포탈의 중력·방향 표식은 실제로 열린 뒤 켠다. 시야 안은 원, 밖은 가장자리 화살표이며 청크 좌표·경계선·타이머는 화면에 표시하지 않는다.
- 포탈 개구는 비워진 면 안에 들어가는 크기와 위치를 추첨한다. **최댓값은 면 전체인 16m×16m**이며 실제로 추첨 가능한 후보로 둔다. 최대 크기에서는 네 변이 면 가장자리에 일치한다. 작은 개구는 먼지·광물·소형 드론만, 기체·차량은 충돌체가 들어갈 만큼 큰 개구만 통과한다. 표시 크기와 물리 개구는 같은 값을 쓴다.
- 시작 입구는 면 채굴과 대기 없이 생성하며 기체가 통과할 수 있다. 이후 포탈은 시작 청크 안에서도 면별 생성 조건을 따른다. 각 통로의 중력 세기는 생성 시 한 번 추첨하고 짝 출구에도 같은 값을 적용한다. 시험 계수는 첫 입구 0.6, 일반 통로 0.8 이상 4.8 미만의 균등분포다.

열린 포탈은 자신이 속한 청크가 초기화되는 순간 소멸하며 중력과 방향 표식도 함께 사라진다. 그 청크의 미개방 예약은 폐기한다. 같은 좌표에 새 청크가 생겨도 이전 포탈은 되살아나지 않는다.

## 여섯 면을 5분 안에 비우면

첫 면이 비워진 시각을 기준으로 마지막 면까지 **300초 이내**에 비우면, 마지막 채굴이 확정된 순간 상·하·좌·우·앞·뒤의 **인접 청크 여섯 곳**을 동시에 생성·연결한다. 대각선 청크는 대상에서 제외한다. 미리 다섯 면을 거의 다 깎아 놓고 남은 블록을 차례로 제거하는 방식도 성립한다.

| 플레이 예시 | 결과 |
| --- | --- |
| 첫 면 12:00, 마지막 면 16:59 또는 17:00 | 마지막 면 채굴과 함께 여섯 이웃이 열린다. 각 면 포탈은 개별 예약 시각에 생성된다. |
| 첫 면 12:00, 마지막 면 17:01 | 동시 생성 조건은 지나갔다. 일반 전진과 각 면 포탈 예약은 유지된다. |
| 첫 면 12:00, 그 면의 추가 지연 추첨 결과 42초 | 그 면의 포탈은 17:42에 열린다. |

표의 시간은 게임 내 분·초다. 여섯 이웃은 현재 공간의 이웃이며 각 면 포탈의 목적지는 별도 시공간이다. 일반 전진으로 먼저 생성한 이웃은 굴착·아이템 상태를 보존하고 누락된 이웃만 만든 뒤 같은 물리 틱에서 여섯 연결을 공개한다. 재시도나 재진입으로 청크·아이템·포탈이 복제되지 않도록 청크 좌표·세대·면을 키로 사용한다.

## 생성된 공간의 네 가지 형태

| 형태 | 배치 | 플레이 |
| --- | --- | --- |
| 꽉 찬 암반 | 모든 칸이 고체인 지형 | 드릴로 전방부터 굴착한다. 실제로 면이 노출될 때 광물 종류를 정한다. |
| 빈 공간 | 모든 칸이 비어 있는 공동 | 체인을 회수하고 시야 방향으로 전진한다. |
| 동굴 | 고체 암벽과 서로 이어진 빈 통로 | 시야를 돌려 통로를 타거나 벽을 뚫어 지름길을 만든다. |
| 부유 창고 | 지형은 비어 있고 물품만 떠다님 | 접근해 장비·생활물품·미지 물질을 회수한다. 창고 구성을 먼저 정하고 개별 물품은 처음 관측될 때 한 번 확정한다. |

여섯 이웃의 형태는 좌표·세대별로 각각 추첨한다. 시작 청크와 포탈 도착지를 포함한 생성 확률은 암반 80%, 동굴 10%, 빈 공간 7%, 창고 3%다. 시작 위치에는 기체 여유 공간과 레이저로 캘 전방 암석 세 개를 확보한다. 창고의 부유 물품은 미리 판정한 광맥으로 취급하지 않는다.

**처음부터 빈 면의 처리 제안.** 플레이어가 그 청크에 처음 들어온 시각부터 원래 빈 면의 포탈 대기를 시작한다. 여섯 면 동시 생성은 실제 채굴로 마지막 면을 비운 경우에만 발동한다. 따라서 완전히 빈 공동이나 창고에 들어가는 것만으로 이웃 청크가 연쇄 증식하지 않는다. 일부 면만 원래 비어 있는 동굴에서는 그 면들을 완료로 세고, 첫 실제 면 채굴 완료 시점부터 5분을 잰다.

## 구현 검수

- 면별 고체 수는 지형 점유 정보로 초기화하고 채굴 커밋 시 줄인다. 여섯 면을 세기 위해 보이지 않는 광물 종류까지 추첨하지 않는다. 남은 블록 하나, 공유 꼭짓점 하나, 같은 채굴 이벤트 재처리를 각각 검사한다.
- 게임 시계는 메뉴를 열어도 진행한다. 앱 비활성화 중에는 진행을 보류한다. 같은 세대에서는 로딩을 반복해도 예약 시각과 크기를 다시 뽑지 않으며, 청크가 붕괴하면 이전 세대 예약을 폐기한다.
- 299.999초·300초·300.001초의 여섯 면 완료, 다른 면에서 동시에 만료된 예약, 면 전체 크기의 개구, 이미 채굴한 이웃 재사용, 빈 창고 연쇄 생성 방지, 일반 경계에서 연속 자동 전진을 검증한다.
