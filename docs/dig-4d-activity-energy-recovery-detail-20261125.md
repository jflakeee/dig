# DIG 4D 기본 활동 에너지·레이저 회수 상세설계

2026-11-25 · 레이저로 먼지·광물을 분해해 기본 에너지와 재료를 회수하는 자원 계약


**구현 상태(2026-11-27, `next/energy.js`, 저장 버전 19).** 수치는 모두 시험값이다.

| 항목 | 구현 |
| --- | --- |
| 버퍼 | 상한 100, 0.5 단위. 상한을 넘는 회수분은 버린다. 이전 저장은 가득 찬 상태로 시작한다. |
| 회수 | 드릴로 블록 하나를 깨면 먼지 분해로 +0.5, 레이저(긴급 레이저)로 블록을 분해하면 +2. 이미 깎인 블록은 다시 주지 않는다(작업 키). |
| 소비 | 세라믹 가열 10, 미지 물질 분석 15, 자동화 연구 20, 원소 분해 5, 포탈 제작 50. |
| 소비하지 않는 것 | 이동·자동 전진·작업등·센서·안전 정지·드릴 채굴·긴급 레이저. 저전력 정책은 "레이저가 에너지 없이 작동"으로 정했다. 에너지가 0이어도 채굴로 다시 차므로 진행이 막히지 않는다. |
| 부족 시 | 해당 버튼만 "에너지 부족 · 필요 N"으로 비활성화하고, 저장 요청도 거부한다(부분 차감 없음). 자동화도 에너지가 모자라면 그 동작을 건너뛴다. |
| 표시 | 메뉴 상단 상태 줄에 `에너지 N / 100`. 인트로에는 표시하지 않는다. |

## 1. 목적과 경계

플레이어 기계의 레이저는 채굴 도구이자 기본 회수 장치다. 먼지와 광물을 분해하면 활동 에너지와 재료를 얻는다. 이 문서는 에너지 저장, 소비, 회수 및 부족 시 동작을 정의한다.

활동 에너지는 내장 기능을 위한 재충전식 자원이다. 자동 전진, 포탈 중력, 기계의 물리적 관성은 에너지 수치로 순간 이동하거나 무시하지 않는다. 이동을 에너지 연료 부족으로 막지 않는다. 과거 무중력 실험의 추진제/부스트 수치는 이 4D 기본 규칙에 직접 적용하지 않는다.

## 2. 저장 자원 구분

| 데이터 | 용도 | 저장 위치 |
| --- | --- | --- |
| 활동 에너지 | 레이저 분해, 암석 가열, 연구/분석 등 능동 작업 | 기계의 에너지 버퍼 |
| 기본 재료 | 레이저 분해에서 얻는 기초 제조 재료 | 플레이어/화물 인벤토리 |
| 광물 재료 | 철·금 등 종류별 광물과 고급 제작 재료 | 플레이어/화물 인벤토리 |
| 먼지 | 분해 시 에너지와 기초 재료 회수에 쓰는 흔한 입자 자원 | 이벤트 결과 후 재료 기록 |

에너지와 재료는 별도 자원이다. 에너지가 가득 찼다고 광물 재료를 버리거나, 인벤토리가 가득 찼다고 에너지를 임의로 재료로 바꾸지 않는다. 활동 에너지는 화물칸에 넣거나 거래하지 않는다.

## 3. 회수·소비 흐름

- 레이저가 먼지를 분해하면 활동 에너지와 기본 재료를 회수한다.
- 레이저가 광물 블록을 분해하면 해당 광물 재료와 활동 에너지를 회수할 수 있다. 광물별 에너지/재료 수율은 설정값이다.
- 레이저가 기본 암석을 분해하면 기본 암석 재료를 회수한다. 일반 암석은 제조 패널에서 별도 가열해 세라믹 부품으로 만들 수 있다.
- 레이저 발사와 암석 가열/분석은 에너지를 사용한다. 작업을 확정하기 전에 예상 에너지 소모와 획득 재료를 표시한다.
- 자동 전진, 작업등의 기본 조명, 중력 센서, 정지/제동은 지속 에너지 소모를 만들지 않는다. 전력 부족 때문에 이동·시야·기본 안전 기능이 꺼지지 않게 한다.
- 기본 작업등 이상의 조명, 연구 장비, 고급 제조 모듈이 에너지를 사용하는지는 선택적 확장으로 남기며, 기본 작업등은 계속 켜져 있어야 한다.

정확한 광물 수율, 레이저 소모, 에너지 용량, 열 가공/분석 비용은 밸런스 설정으로 둔다. 에너지 회수와 소비가 같은 이벤트에서 일어나면 순소모량과 최종 버퍼를 미리 계산한 뒤 확정한다.

## 4. 부족 상태와 진행 보장

에너지가 부족하면 필요한 에너지 작업만 정지하고 필요한 양을 알려 준다. 채굴 가능한 먼지가 보이면 레이저 저전력 회수 동작을 제안한다.

- 저전력 회수는 먼지 분해만 수행하고, 일반 광물 채굴·가열·연구는 하지 않는다.
- 저전력 회수에도 최소 작동 에너지가 필요할 경우를 대비해 비상 reserve를 남긴다. 비상 reserve의 용량과 발동 기준은 밸런스 설정값이다.
- 비상 reserve가 부족해도 플레이어 이동·메뉴·작업등·센서는 유지한다. 에너지를 회수할 수 있는 먼지나 광물이 작업등/센서에 보이면 이동을 강제하지 않고 안내한다.
- 먼지 회수 가능성이 없는 상태에서 에너지 소진이 생기지 않도록, 기본 이동과 기본 시야는 에너지 소모 대상에서 제외한다.
- 에너지 0이 장비 파괴, 세이브 삭제, 영구 이동 불능으로 이어지지 않는다. 다시 회수 가능한 기본 자원 루프를 제공한다.

저전력 레이저가 에너지 없이 작동할지, 비상 reserve를 통해 작동할지는 구현 전에 선택해야 할 세부 정책이다. 어느 쪽이든 플레이어가 영구적으로 진행 불가 상태에 빠지지 않는 것이 필수 기준이다.

## 5. 에너지 용량·초과 회수

활동 에너지는 기계 내부 버퍼에 저장되며 상한을 가진다. 회수 결과가 상한을 넘으면 초과분만 버리고 광물/기본 재료는 정상 수집한다. 수집 전에 현재/회수량/상한/낭비 예상량을 한눈에 확인할 수 있다.

에너지 버퍼 확장 장비를 추가할 경우 기존 에너지를 비율로 변환하거나 삭제하지 않고 절대량을 유지한다. 최대 용량보다 높은 저장값을 읽는 오래된 세이브는 새 상한으로 안전하게 보정한다.

## 6. 원자성·중복 방지

레이저 채굴 이벤트는 발견 상세설계에서 확정된 블록 결과를 이용한다. 작업 ID 하나에 아래 작업을 연결한다.

1. 현재 에너지와 대상 블록 상태를 검사한다.
2. 발사 에너지를 예약한다.
3. 블록 제거, 광물/먼지 결과, 기본 재료, 에너지 획득을 계산한다.
4. 에너지 버퍼 상한, 인벤토리/화물 공간을 확인한다.
5. 블록 상태·자원·에너지를 하나의 저장 이벤트로 커밋한다.

저장 실패 시 블록 제거·에너지 차감·재료 지급을 모두 되돌린다. 재시도는 같은 작업 ID와 고정된 발견 결과를 재사용해 이중 지급이나 에너지 복제를 막는다. 부분 적재만 허용되는 경우에는 획득하지 못한 재료를 청크 바닥 드롭으로 남기고 에너지까지 함께 버리지 않는다.

## 7. HUD와 버튼

- 에너지 숫자/막대는 화면 정보로 표시하되 항상 경고색으로 강조하지 않는다.
- 에너지가 특정 작업의 요구량 아래로 내려가면 그 작업 버튼을 메뉴에서 숨기거나 비활성화하고 부족량을 표시한다.
- 회수 가능한 먼지/광물이 있을 때만 저전력 회수 행동을 제안한다.
- 일반 암석 3개 인트로 동안은 에너지 수치나 시스템 설명을 별도 HUD로 추가하지 않아 기존 어두운 도입을 방해하지 않는다.
- 자원 소모가 큰 작업에는 실행 전 최종 에너지와 재료 미리보기를 제공한다.

## 8. 미정값과 완료 기준

미정: 에너지 버퍼 용량, 먼지/광물별 회수량, 레이저 소비량, 저전력 최소 동작 및 비상 reserve 정책, 암석 가열·분석 비용, 확장 버퍼, 인벤토리 공간 부족 시 회수 처리.

완료 기준:

- 레이저로 먼지/광물을 분해해 활동 에너지와 기초 재료를 회수한다.
- 이동·기본 조명·중력 센서·안전 제동은 에너지 고갈로 정지하지 않는다.
- 에너지 소진은 선택된 능동 작업만 멈추며 기본 회수로 복귀할 수 있다.
- 버퍼 초과, 인벤토리 만재, 저장 실패와 재시도에서 자원 복제/부분 차감이 없다.
- 노출 블록 결과는 발견 시스템에서 한 번 정해진 뒤 에너지 보상 계산이 이를 다시 굴리지 않는다.
- 수치 튜닝 후에도 저전력/비상 회수 경로가 끊겨 영구 진행 불가가 되지 않는다.
