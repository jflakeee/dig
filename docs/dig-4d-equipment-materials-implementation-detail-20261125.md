# DIG 4D 드릴·레이저·세라믹 장비 진행 상세설계

2026-11-25 · 기본 레이저에서 드릴 제작·강화·수리와 긴급 채굴까지 이어지는 장비 규칙

## 1. 설계 범위

플레이어는 레이저·조명·연구·제조 기능이 내장된 AI 구체형 채굴 기계다. 별도 매점 없이 내부 제조 기능과 조건부 버튼을 사용한다. 이 설계는 4D 채굴 모드의 장비 루프를 정의하며 클래식 광산 장비 표나 실험 프리뷰의 숫자를 그대로 이식하지 않는다.

## 2. 장비 역할

| 장비 | 역할 | 진행 규칙 |
| --- | --- | --- |
| 기본 레이저 | 암석·광물·먼지를 분해하고 기본 활동 에너지/기초 재료를 회수. 일반 암석을 가열해 세라믹 부품을 제조 | 처음부터 장착된 기본 장비이며 드릴이 고장 나도 긴급 채굴 가능 |
| 드릴 | 일반 자동 채굴의 주 장비. 몸체가 통과할 갱도를 파고 전방 자동 전진을 연다 | 사용 중 확률적으로 손상. 내구도 0이면 일반 드릴 채굴 정지 |
| 추가 드릴 | 추가 채굴 도구를 제작·장착해 병렬 채굴 또는 교대 사용 | 병렬 효과와 동시 작동 상한은 확장 설계값. 추가 드릴도 각각 내구도와 강화 단계를 보유 |
| 세라믹 부품 | 레이저로 암석을 열 가공해 얻는 기본 제조 부품 | 상위 장비 제작과 여러 장비의 강화에 폭넓게 사용 |
| 광물 재료 | 발견된 모든 광물 자원 | 장비 제작과 강화 재료로 쓸 수 있다. 특정 광물이 모든 레시피에 들어갈 필요는 없다 |

## 3. 시작 인트로와 제조 해금

1. 시작 시 레이저는 기본 장착 상태이고 다른 장비/메뉴 버튼은 숨긴다.
2. 레이저로 일반 암석을 수집한다. 누적 3개에 도달하면 드릴 제작 버튼만 표시한다.
3. 제작을 확정하면 암석 3개를 원자적으로 소비하고 기본 드릴 1개를 만든다. 제작 직후 드릴을 전방에 장착한다. 정지는 자동 채굴·전진 실행 중, 재개는 안전하게 작업을 다시 시작할 수 있을 때만 표시한다.
4. 드릴 장착 후 체인을 고정하고 자동 채굴한다. 몸체가 통과할 폭이 확보되면 체인을 회수하고 자동 전진한다.
5. 그 뒤에는 조건을 만족하는 기능만 메뉴에 노출한다. 재료가 부족하거나 슬롯이 없으면 버튼을 감추거나 비활성화 상태와 부족 재료를 명확히 표시한다.

인트로 드릴 제작은 첫 플레이를 열어주는 고정 레시피다. 이후 드릴 추가·강화·수리 레시피와 혼합하지 않는다.

## 4. 레이저 처리 루프

레이저 작업은 한 번의 처리 이벤트로 대상 블록, 활동 에너지 회수, 기본 재료 획득, 발견물 결과 연결을 묶는다.

- 암석은 분해하여 일반 암석 재료를 얻고, 제조 패널에서 가열 공정을 거쳐 세라믹 부품으로 바꿀 수 있다.
- 광물은 종류에 맞는 광물 재료와 활동 에너지를 회수한다. 자원마다 에너지/재료 수율은 조정 설정값이다.
- 먼지는 분해해 기본 활동 에너지를 보충할 수 있다. 먼지에서 고급 광물이나 임의 아이템을 만들지 않는다.
- 레이저로 블록을 제거할 때도 블록 노출 시 이미 고정된 발견 결과를 사용한다. 레이저와 드릴이 별도로 광물 결과를 다시 뽑지 않는다.
- 가열 제조에는 에너지·재료 소모를 둘 수 있으나 비용과 처리 시간은 미확정 설정값이다.

레이저 작업은 제작/수리 버튼으로 재료를 소비하는 순간에도 같은 저장 트랜잭션 규칙을 따른다.

## 5. 드릴 상태·손상·수리

드릴별 상태는 장착 가능 → 장착 → 채굴 중 ↔ 정지 → 손상 → 수리 필요로 관리한다. 내구도는 드릴 개체별 저장값이다.

- 내구도는 채굴 작업 완료 이벤트에서 확률적으로 감소한다. 이동 시간, 메뉴 대기, 포탈 흡인, 체인 고정만으로는 내구도를 소모하지 않는다.
- 같은 채굴 이벤트가 재시도되어도 손상 판정과 보상은 한 번만 반영한다.
- 내구도가 0이 되면 해당 드릴로 진행 중인 블록 채굴을 안전하게 마무리할 수 없는 경우 작업을 취소하고 정지한다. 이후 정상 채굴은 레이저나 다른 내구도 있는 드릴로만 가능하다.
- 수리 버튼은 드릴 손상과 수리 재료 충족 때만 표시한다. 재료·에너지·내구도 회복은 한 번에 저장한다.
- 수리는 장비 최대 내구도까지 복구한다. 수리 횟수에 따른 영구 내구도 감소나 단계 하락은 이번 설계에서 추가하지 않는다.
- 수리 재료가 부족하면 수리를 실행할 수 없고, 필요한 재료와 보유량을 보여 준다.

손상 확률, 손상량, 기본 내구도, 수리 재료 조합과 수량은 밸런스 설정으로 남긴다. 이전 무한 지하 프리뷰 수치를 4D 기본값으로 사용하지 않는다.

## 6. 내구도 0 긴급 채굴

드릴 내구도가 0이고 수리 재료가 부족하면 기본 레이저가 비상 채굴을 제공한다.

1. 일반 드릴 자동 채굴을 멈추고 화면에 긴급 채굴 버튼과 느린 레이저 속도를 안내한다.
2. 플레이어는 레이저를 조준해 광물/암석 블록을 하나씩 천천히 분해한다. 고속 범위 채굴이나 자동 전진은 하지 않는다.
3. 레이저 결과는 일반 노출·채굴 결과 규칙을 사용한다. 재료를 얻어도 해당 이벤트를 중복 지급하지 않는다.
4. 수리 재료 조건을 충족하면 수리 버튼을 표시한다. 수리 완료 전까지 드릴 자동 채굴은 재개하지 않는다.
5. 주변에 채굴 대상이나 레이저 에너지가 없으면 이동을 강제하지 않고 정지 상태와 필요한 조치를 보여 준다.

긴급 채굴의 정확한 속도 비율, 레이저 에너지 비용, 수리 재료로 인정되는 광물 목록은 미정이다. 레이저가 기본 생존 경로인 만큼 플레이어가 청크/인벤토리 상태 때문에 영구적으로 진행 불가능해지지 않도록 최소 한 가지 회복 경로를 둔다.

## 7. 드릴 추가 제작·강화

- 기본 드릴을 가진 뒤 제작 패널에서 추가 드릴을 제작할 수 있다. 제작 완료 후에는 자동 장착하지 않고 보유 목록에서 장착/교체한다.
- 추가 드릴은 각자 내구도, 강화 단계, 식별자를 보유한다. 장착 상태만 바뀌며 기존 드릴의 손상이나 강화가 다른 드릴로 이동하지 않는다.
- 레이저는 강화 작업을 수행한다. 세라믹 부품은 여러 상위 장비의 공통 재료이며, 광물은 제작/강화 레시피별 전문 재료로 배정할 수 있다.
- 강화는 단계별 레시피와 효과를 미리 보여주고, 플레이어 확정 후 재료를 소비한다. 강화 효과 예시는 채굴 속도, 내구도 효율, 레이저 에너지 효율, 병렬 드릴 지원이다. 구체 효과·단계 상한·성공률·실패 손실은 아직 결정하지 않는다.
- 이전 설계의 강화 확률이나 클래식 광산의 전설 장비 수치를 4D에 적용하지 않는다. 실패 시 재료를 잃는지, 단계가 하락하는지, 보호 재료를 두는지는 별도 밸런스 결정으로 남긴다.

## 8. 조건부 UI와 저장 안전성

| 상황 | 표시 버튼 | 확정 전 확인 |
| --- | --- | --- |
| 일반 암석 3개 확보, 드릴 없음 | 드릴 제작 | 암석 3개 소모 |
| 드릴 손상 및 재료 확보 | 수리 | 재료 소모와 내구도 회복 |
| 제작 재료/슬롯 확보 | 드릴 추가 | 재료 소모와 보유 드릴 수 |
| 강화 재료 확보 | 드릴 강화 | 단계·효과·소모 재료 |
| 드릴 내구도 0, 수리 재료 부족 | 레이저 긴급 채굴 | 느린 채굴 방식과 목표 재료 |

제작·강화·수리는 현재 세이브 revision을 확인하고 재료 차감, 장비 상태 갱신, 로그 기록을 하나의 원자적 작업으로 저장한다. 이중 클릭·재시도는 동일 작업 ID로 한 번만 처리한다. 저장 충돌이면 자원을 차감하지 않고 최신 보유량을 다시 표시한다.

## 9. 미정 설정과 완료 기준

미정 설정: 기본 드릴 내구도·손상 확률·손상량, 수리 재료와 비용, 레이저 처리량/에너지, 세라믹 수율, 추가 드릴 제작 상한, 병렬 채굴 효과, 강화 단계·비용·효과·실패 규칙.

완료 기준:

- 시작 암석 3개로 기본 드릴을 제작하면 자동 장착되고 인트로 흐름이 이어진다.
- 레이저는 드릴과 별도로 기본 활동 에너지/기초 재료 회수와 세라믹 제조를 지원한다.
- 드릴 손상과 수리는 채굴 작업에만 연동되고 개별 드릴 저장값을 가진다.
- 내구도 0·수리 재료 없음에서 레이저 긴급 채굴로 회복 가능한 루프가 있다.
- 세라믹과 각 광물은 장비 제작·강화에 사용될 수 있고, 구체 재료 수량은 확정 전 설정값이다.
- 저장 오류·중복 입력에서 재료, 내구도, 강화 단계가 부분 적용되거나 중복 차감되지 않는다.
- 모든 수치는 4D 플레이 검증 전 확정값으로 취급하지 않는다.
