## 2026-11-24 재검토: 통로 생성과 물리 규칙

### 확정된 규칙

- 새 청크가 생성될 때 대형 통로는 3%, 소형 통로는 10% 확률로 존재 여부를 판정한다.
- 플레이어가 해당 청크에 진입하면 통로 주변의 미세중력을 센서로 감지하고 표시한다.
- 소형 통로는 광물과 소형 드론만 통과할 수 있고, 대형 통로는 채굴 기계와 열차가 통과할 수 있다.
- 통로는 입구/출구 한 쌍이며 한 방향으로만 이동한다. 통과는 순간이동이 아니라 물리적으로 끌려 들어가 반대편으로 빠져나오는 흐름이다.
- 입구 주변의 중력 효과는 먼지·광물·드론·채굴 기계·열차를 끌어당기는 물리 효과로 표현한다. 별도 순간이동 입력이나 강제 위치 스냅은 사용하지 않는다.
- 열차 전체가 통과하면 이전 청크 환경을 초기화한다. 출구에서는 가끔 광물 또는 장비가 떨어진다.
- 현재 구현 기반은 통로 필드의 가속도 계산과 채굴 기계 이동뿐이다. 먼지·광물·드론·열차의 관성, 충돌, 마찰과 통로 통과 처리는 미구현이다.

### 다음 구현 단위

1. 세션 청크 생성 시 소형/대형 통로 후보를 확률 판정하고 쌍의 방향 및 입출구 데이터를 런타임 전용으로 보관한다.
2. 청크 진입 시 센서가 근처 통로 중력 신호를 표시한다.
3. 통로 중력장을 물체 시뮬레이션에 적용한다. 우선 기계·열차·드론은 고정 단계의 물리 업데이트와 복셀 충돌을 사용하고, 먼지·광물은 묶음/저비용 업데이트로 모바일 성능을 제한한다.
4. 통로를 실제로 통과한 열차 꼬리가 출구를 완전히 벗어난 뒤에만 이전 청크를 초기화한다.
5. 출구 방출 광물/장비는 낮은 빈도로 생성하고 회수 여부를 열차 인벤토리에 반영한다.

### 추가 확인이 필요한 항목

“무작위” 응답은 소형·대형 통로 생성 판정의 관계인지 통로 방향 선택인지 명확하지 않아, 독립 판정/한 청크당 하나 제한/통로 방향 중 어느 규칙인지 아직 고정하지 않는다. 방향·확률 계산은 이 선택에 맞춰 테스트한다.


### 통로 확률 판정 추가

- 확정: 새 청크 생성 때 소형 통로 10%, 대형 통로 3%를 독립 판정한다. 따라서 두 통로가 모두 없거나, 하나만 있거나, 둘 다 있을 수 있다.
- `src/digMode/portalGeneration.ts`의 독립 판정 함수를 `SessionChunks` 최초 청크 생성에 연결했다. 판정 결과는 세션에서 청크별로 유지되며 청크 초기화/통로 전환 시 함께 제거된다. 재접속 때 월드와 함께 사라진다.
- 아직 통로 쌍 배치·센서 표시·물리 객체 이동에는 연결하지 않았다.
- 자동 검증은 네 가지 확률 결과, 잘못된 난수 입력, 세션 내 결과 유지, 청크 초기화와 전체 환경 전환 시 제거를 확인한다. CI 전용 4D 검증 워크플로에서 복원 스모크와 함께 실행한다.
- 통로 쌍의 입출구 방향은 무작위라는 확정이 없으므로 기존 문서에서 미확정으로 유지한다.
