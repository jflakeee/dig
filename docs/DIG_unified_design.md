# DIG 통합 게임 설계서

2026-11-25 · 4D 무한 채굴을 중심으로 통합한 설계 기준 · 시작 장면/조명 최신 결정 반영

## 1. 게임의 방향

DIG는 모바일 우선 3D 자동 채굴·탐험 게임이다. 플레이어는 손상된 자전적 기억을 가진 구체형 자율 채굴 기계를 조종한다. 하늘과 지표면이 없는 지하에서 광석을 캐고, 우주 곳곳의 물품이 모이는 4차원 통로를 발견한다. 선두 기계와 화물차를 성장시키며 채굴, 물질 연구, 제작, 거래를 이어 간다.

**플레이 흐름** · 방향 조정 → 자동 전진과 채굴 → 물품 회수 → 드릴·열차 성장 → 통로 탐색과 이동 → 연구·제작·거래 → 다음 탐험.

기존 4개 광산은 별도 클래식 모드로 유지한다. 무한 지하 프리뷰에서 실험한 기능은 4D에 채택할 때 적용 범위를 정한다. 멀티플레이는 싱글플레이 안정화 이후의 보류 설계다.

## 2. 오프닝과 조작

- **첫 화면부터 완전히 막힌 지하에서 시작한다.** 기계가 안전하게 들어갈 최소 공간만 비우고, 상·하·좌·우·앞·뒤 여섯 방향은 광물층 암반으로 막는다. 미리 뚫린 전방 터널이나 탁 트인 시작 공동은 두지 않는다. 시작 시점에 화면에는 가까운 암반 표면만 보인다.
- 게임 전체의 기본 화면은 어둡게 유지한다. 주변광을 올려 공간 전체를 밝히지 않으며, 작업등 빛이 닿는 범위만 보인다. 오프닝의 조명·드릴음 상승 연출은 작업등 빔 안에서만 짧게 진행할 수 있고, 이후에도 밝은 전체 화면으로 전환하지 않는다. 먼지·통로·HUD도 주변을 환하게 만드는 광원으로 쓰지 않는다.
- 기계는 자동 전진하다 전방 암반에 닿으면 정지해 채굴하고, 통로가 열리면 다시 전진한다. 방향을 돌리면 해당 면도 암반에 막혀 있다. 광물은 자동 수집한다. 드릴이 암반을 제거할 때만 새 공간이 열리며, 작업등이 그 공간을 제한적으로 드러낸다.
- 사용자는 왼쪽 스틱으로 추진하고 오른쪽 화면을 드래그해 방향을 바꾼다. 위아래를 바라본 뒤 전진하면 수직으로 이동한다. 기본 추진은 광물 부족으로 막히지 않도록 부산물 재활용과 비상 추진으로 유지한다. 선택적 고출력 추진은 후속 성장 후보로 둔다.
- 기본 화면에는 메뉴 버튼 하나를 둔다. 메뉴를 열면 공유·복원·처음부터 다시 시작 등 관리 기능을 표시한다. 드릴 강화·추가·거래·경매는 실제 조건이 갖춰진 행동만 상황에 맞게 표시하는 것이 목표다. 오프닝에서 안내하는 성장 행동은 드릴 강화와 추가다.
- 화면 회전·터치 취소·앱 비활성화 시 눌림 상태를 해제한다. 복원 중에는 자동 채굴을 멈춘다. 미로딩 구역이나 저장 실패 시의 안전 정지와 일시정지·재개 동작도 검증한다.
- 기계는 작업 기억을 유지하지만 이름·얼굴·약속 같은 개인 기억이 드물게 떠올랐다가 사라진다. 재접속 독백은 열차 기록이 있는 경우에만 사용하고 새 게임에서는 생략한다. 기억 손상은 서사 설정으로, 인벤토리와 저장 데이터는 정상적으로 유지한다.

## 3. 무한 지하와 광물

| 항목 | 통합 기준 |
| --- | --- |
| 공간 | X/Y/Z 방향으로 이어지는 지하. 0.5m 복셀, 한 변 16m 청크(32³복셀), 메시 부분 갱신 구역은 8³복셀(한 변 4m) |
| 활성 범위 | 32m 이내 활성, 64m 이내 근거리 유지, 64–256m는 세션 상태를 보존하고 시야에 따라 메시 유지·해제 |
| 먼지와 붕괴 | 224m부터 먼지가 짙어져 256m에 가림. 256m 밖 청크 기록은 세션에서 제거. 거리 규칙은 기기 성능과 무관하며 시각 품질과 메시로 최적화 |
| 광물 | 숨은 블록은 처음 노출될 때 결정. 전역 확률은 암석 65%, 석탄 18%, 철 10%, 금 5%, 희귀 2%. 깊이·지역·강화는 기본 가중치에 영향 없음 |
| 세션 보존 | 같은 세션의 보존 범위 안에서 굴착·광물 상태를 유지. 원거리 초기화 후 재생성 시 다시 판정. 재접속 및 대형 통로 전환에서는 이전 환경·위치·통로 연결을 폐기 |
| 시설 | 지상 매점 건물과 보호구역을 두지 않는다. 제작과 거래는 메뉴 및 드론으로 연결 |

자연 공동과 플레이어가 제거한 블록을 구분한다. 한 블록의 제거, 수집 보상과 후속 마모·추가 드롭이 중복 처리되지 않게 한다. 초기 1m 캐릭터와 채굴 간격 3배는 클래식 P18 작업 브랜치의 변경이다. 4D 기계의 현재 충돌 반경은 0.32m이며 4D의 별도 채굴 속도 밸런스는 이 값과 독립적으로 검증한다.

## 4. 4차원 통로와 중력

| 규칙 | 소형 | 대형 |
| --- | --- | --- |
| 새 청크 출현 | 10% | 3% |
| 통과 대상 | 광물·소형 드론 | 구체형 선두 기계와 열차 |
| 이동 결과 | 통로를 통해 물품과 드론이 이동 | 열차 후미가 출구를 완전히 통과하면 이전 환경을 초기화하고 새 출구 환경으로 전환 |

두 확률은 독립 판정한다. 둘 모두, 하나, 둘 다 없는 경우가 생긴다. 각 통로는 입구와 출구가 한 쌍이며 한 방향으로 물리적으로 이동한다. 입구에서는 안쪽으로 끌리고 출구에서는 바깥쪽으로 밀려난다. 통로 밖에서는 통로 중력이 없고, 센서는 가까운 통로의 중력 신호를 표시한다. 입구는 흡인 효과를 보여 주며 광물·장비의 생성은 출구 쪽에 둔다.

출구는 처음에 광석으로 가려지고 이를 채굴하면 통로가 드러나는 것이 목표다. 방출 빈도는 채굴보다 느리게 두며, 광물이나 장비가 가끔 나온다. 구체적인 간격과 물품 확률은 미정이다. 현재 프로토타입의 소형·대형 방향은 각각 +Z·+X이며, 방향 무작위화는 확정 수치 없이 후속 검토한다.

## 5. 열차와 성장

- 선두차 한 량에 채굴차·기관차·연구차의 기능을 통합한다. 뒤에 연결되는 차량은 모두 화물차다. 대형 통로에서는 선두 장비가 경로를 파고 열차가 뒤따른다.
- 열차에 실린 장비·인벤토리·연구·도감은 통로 이동과 재접속 후 유지한다. 바닥에 놓인 물품은 환경 초기화 때 사라진다. 길어진 후미가 초기화 경계 밖 청크에 남으면 차량과 적재물이 소실될 수 있다. 현재 구현은 추종차 한 량이며 다중 차량의 경계 판정과 관리 UI는 남아 있다.
- **드릴 강화**는 기존 드릴의 채굴 성능을 높이고 **드릴 추가**는 병렬 채굴 능력을 더하는 설계다. 현재 구현은 강화 단계와 드릴 수의 상한 5를 기준으로 버튼을 표시한다. 재료 비용·복수 드릴의 실제 효과·표시 조건은 구현과 밸런스 검증이 필요하다. 드릴 성장이 출구 방출 속도를 높이지는 않는다.
- **드릴 고장 시 긴급 경로:** 드릴 내구도가 0이고 수리에 필요한 재료가 없어 수리할 수 없을 때, 레이저로 광물을 느린 속도로 긴급 채굴해 수리 재료를 마련할 수 있다. 이를 통해 채굴 진행이 막히지 않게 한다. 속도·대상 광물·레이저 에너지/소모 규칙은 미정이다.
- 연구는 새 물질의 발견과 분석을 도감에 연결한다. 현재 연구·도감 ID를 저장하며 콘텐츠·해금·보상은 후속이다.
- 무한 지하 프리뷰의 칸당 40개, 최대 8칸, 엔진 5단계와 적재량 감속은 프리뷰 기준이다. 4D 열차의 용량·길이·엔진 확정값으로 사용하지 않는다.

## 6. 제작·발견물·거래

일반 암석을 레이저로 가열해 세라믹 도구를 만든다. 세라믹 도구는 용광로 같은 상위 장비의 제작에 사용한다. 발견물은 보석, 외계 금속, 외계 생물 중합체, 지구 물건, 정체 미상의 외계 물질까지 확장한다. 품목별 물성, 연구 조건, 레시피와 상위 장비 비용은 미정이다.

소형 거래 드론이 외계 거래 상대에 연결한다. **표시 가격이 있는 물품은 판매·구매**, **가격이 없는 물품은 경매 등록**이 가능하다. 경매 기간, 정산 시점, 유찰·취소, 크레딧 및 특별 화물 승인 규칙은 후속 결정이다. 현재 통로를 지나는 소형 드론 표현은 구현됐으며 실제 거래·경매는 설계 단계다.

### 성장 경제 후보

| 항목 | 프리뷰·무한 지하에서 검토한 값 |
| --- | --- |
| 강화 +0~+5 | 채굴 시간 단축 0/8/16/24/32/40%, 동시 제거 1/1/1/2/2/3, 추가 드롭 발생 10/11/12/14/17/20% |
| 추가 드롭 | 기본 발생 10%, 발생 시 일반/고급/희귀/영웅/전설 60/25/10/4/1 비율. 전설 미획득 추가 드롭 500회 후 다음 추가 드롭 보장 제안 |
| 내구도와 수리 | 초기 1,000, 일반 암석 1·단단한 암석 2–5 마모 제안. 수리당 최초 최대 내구도 1% 감소·50% 하한. 보호 재고를 유지하며 자동 수리 기본 꺼짐 |
| 강화 성공률 | 100/85/70/55/40% 제안. 상위 두 강화 실패의 단계 하락은 보호석으로 방지하는 안 |
| 판매 기준 | 암석/석탄/철/금/희귀 1/4/10/25/100G 제안. 기본 보상 기대 총매출 5.62G/블록 |
| 경제 검증 | 4장비×6강화×1·10·100시간×100시드의 7,200회 모형. 시간당 순수익·장비 수명·희귀 보상 시간 비교 |

이 표는 4D 배포 밸런스 확정값이 아니다. 청크 초기화로 장비 마모나 천장 기록이 되돌아가지 않게 하며, 유료 확률형 보상과 현금 교환은 설계에서 제외한다.

## 7. 저장·공유·처음부터 다시 시작

1. 4D 전용 저장에 열차 진행만 보관한다. 청크·위치·통로·월드 생성 정보는 환경과 함께 초기화한다.
2. 공유된 DIG4R1 코드는 복원 입력으로 사용할 수 있다. 입력 형식과 버전, 체크섬, 열차 스키마를 확인한다.
3. 적용 직전 현재 진행의 백업 코드를 **클립보드에 복사**한다. 자동 복사가 실패하면 수동 복사 후 확인받고, 취소되거나 저장 충돌이 있으면 현재 기록을 보존한다.
4. 백업이 확보된 뒤 현재 열차 진행을 가져온 기록으로 교체한다. Base64URL은 공유 형식이며 CRC32는 우발적 손상을 감지한다. 이메일 인증·발송을 쓰던 흐름은 클립보드 방식으로 대체됐다.
5. 처음부터 다시 시작은 확인 후 4D 열차 기록을 지운다. 클래식 광산 저장은 별도 키와 기존 호환 규칙으로 관리한다.

## 8. 클래식 광산과 온라인

**클래식.** 현재 공개된 4개 유한 광산에서 삽·곡괭이·드릴로 수동 채굴하고, 지상 캠프에서 판매·제작·강화한다. 광산 Ⅰ은 기본 개방, Ⅱ·Ⅲ은 이전 광산 굴착도로 해금하며 Ⅳ는 화산 광산이다. 자연 동굴·수정·유물·보물상자·특수 지층·도감은 안정된 발견 ID와 저장 호환을 유지한다. 광산 Ⅴ 최종 성소, 최종 유물, 엔딩 후 자유 탐험은 미완료 과제로 둔다.

**온라인.** 협력은 광물별 균등 분배와 나머지 이월, 수집량 대결은 동일 시작 조건과 서버 검증 점수, 약탈은 동의한 방에서만 허용하고 비보호 광물의 최대 20%를 이전한다. 2–4인 방, 서버 권위 정산, 접속 복구, 온라인·싱글 재화 분리를 전제로 한다. 서버·매칭·동기화·PvP 구현은 보류한다.

## 부록 · 기존 광산 설계 세부사항

### 1. 게임 개요와 플레이 흐름

DIG는 모바일 우선 1인칭 3D 채굴·탐험 게임이다. 지상 캠프에서 출발해 지하를 파고, 광물과 발견물을 수집한 뒤 캠프로 돌아와 판매·제작·장비 강화를 한다. 성장한 장비로 더 깊은 지층과 다음 광산을 탐험한다. 깊이가 늘어날수록 지층, 조명, 광물뿐 아니라 동굴, 보물상자, 유물 등 발견 대상이 달라진다.

- **굴착**은 복셀 지형의 제거와 충돌 갱신을 연결한다. 삽·곡괭이·드릴은 채굴 간격, 범위, 거리로 역할을 나눈다.
- **모바일 조작**은 왼쪽 가상 조이스틱으로 이동하고 오른쪽 화면을 드래그해 시점을 바꾼다. 굴착 버튼은 길게 눌러 연속 사용하고, 모바일 터치와 PC의 WASD 조작을 지원한다.
- **지상 복귀**는 채굴로 지형이 달라져도 안전한 위치로 돌아올 수 있도록 한다. 매점과 제작소는 채굴 주기의 거점이다.
- **시각과 소리**는 깊이별 색상과 조명, 광물 발광, 도구별 타격음과 파편, 희귀 발견 연출로 채굴 결과를 전달한다.

### 2. 기존 광산 P18 작업 브랜치의 결정

| 항목 | 적용 기준 | 대화 마지막 상태 |
| --- | --- | --- |
| 캐릭터 | 높이 **1m**. 충돌 판정과 깊이 계산을 새 높이에 맞춤 | 작업 브랜치 반영 |
| 블록 | 한 변 **0.5m**. 캐릭터 높이의 절반 | 기존 크기 유지 |
| 삽 | 기본 채굴 간격 180 → **540ms** | 작업 브랜치 반영 |
| 곡괭이 | 기본 채굴 간격 350 → **1,050ms** | 작업 브랜치 반영 |
| 드릴 | 기본 채굴 간격 90 → **270ms** | 작업 브랜치 반영 |
| 시설 보호 | 매점(TRADE)과 제작소(CRAFT) 주변 약 **2.5m**, 지표면 아래 **2m**까지 채굴 제한. 구역 밖에서는 정상 채굴 | 작업 브랜치 반영 |
| 무한 월드 | 기존 광산 본체의 무한 월드 전환안 | 별도 4D 런타임이 main에 구현됨 |

채굴 시간은 기존의 3배로 늘리고 강화 효과는 유지한다. 블록 크기 0.8m는 캐릭터 높이를 1.6m로 가정한 검토 수치였다. 시설 보호는 기존 저장 형식을 유지한다. 마지막 채굴 테스트 수정은 강화 후 기대값을 507ms에서 508ms로 정정한 것이다.

### 3. 광산과 탐험 콘텐츠

광산별 지형과 굴착 이력을 개별로 보존하고 인벤토리, 경제, 장비 성장은 광산 간 공유한다. 지상에서 해금된 광산으로 이동한다. P4 설계에서 제시된 첫 세 광산의 크기와 해금 조건은 아래와 같다. 후속 아트 설계에서 II·III의 테마 명칭이 달라진 이력이 있어 번호를 기준으로 정리했다.

| 광산 | 설계 역할 | 크기·해금 또는 상태 |
| --- | --- | --- |
| I | 초원 광산. 채굴과 성장을 익히는 시작 지역 | 16×16×12m, 기본 개방 |
| II | 협곡·수정 테마. 동굴과 희귀 수정 탐험 | 24×24×18m, I의 10% 굴착 조건 |
| III | 심층 수정·고대 유적 테마. 심층 발견물 확장 | 32×32×24m, II의 15% 굴착 조건 |
| IV | 화산 지대. 흑요석·용암·고대 기계장치 테마 | P11에서 게임 연결 및 배포 보고 |
| V | 최종 성소. 최종 유물과 엔딩의 목적지 | 설계 존재, 구현 확인 필요 |

P8에서는 일반 광물(0–3m), 작은 동굴(3–6m), 광물 군집과 상자(6–9m), 고대 유물(9–12m), 희귀 수정 동굴(12–18m), 특수 지층과 전설급 유물(18–24m)로 발견의 깊이를 단계화했다. 동굴과 수정 군집, 보물상자, 유물, 특수 지층, 발견 도감을 게임에 연결한 기록이 있다. 자연 동굴은 시드 기반으로 생성하고, 플레이어 굴착 기록과 분리해 해금 진행률·채굴 보상을 계산한다. 발견 보상은 재진입이나 저장 복원으로 중복 지급되지 않도록 한다.

### 4. 경제·제작·장비 성장

| 기본 광물 | 초기 설계 등장 깊이 | 초기 판매가 |
| --- | ---: | ---: |
| 석탄 | 1m 이상 | 2G |
| 구리 | 2m 이상 | 5G |
| 철 | 4m 이상 | 9G |
| 금 | 6m 이상 | 25G |
| 보석 | 8m 이상 | 80G |

깊이와 판매가는 P2의 설계 기준이다. 후속 광산에서는 광산별 분포를 적용한다. 수집한 광물은 판매해 골드를 얻거나 제작 재료로 보존한다. 석탄 연료는 굴착 속도, 구리 합금은 굴착 거리, 강철 주괴는 굴착 반경, 보석 코어는 조명 거리를 늘리는 성장 효과로 연결했다. 제작과 강화의 소모·보상은 저장 및 복원 후에도 일관돼야 한다.

| 전설 장비 | 특화 효과 | P11 제작 조건 |
| --- | --- | --- |
| 지진 삽 | 굴착 반경 +25%, 간격 +20% | 흑요석 심장 12, 불꽃 수정 3, 고대의 핵 1 |
| 화염 곡괭이 | 굴착 거리 +25%, 간격 +10% | 흑요석 심장 16, 불꽃 수정 4, 고대의 핵 1 |
| 코어 드릴 | 굴착 간격 −20%, 반경 −10% | 흑요석 심장 20, 불꽃 수정 6, 고대의 핵 2 |

전설 장비는 각 기본 장비의 +5 강화를 요구하는 설계다. 세 초희귀 광물의 P11 설계값은 흑요석 심장 0.2%·150G, 불꽃 수정 0.05%·500G, 고대의 핵 0.01%·2,000G다. 장비 효과와 재료 요구량은 P11 설계 기준이며 P18의 채굴 간격 변경을 적용한 뒤 체감 밸런스 확인이 필요하다.
