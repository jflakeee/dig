# DIG 통합 게임 설계서

2026-11-25 · 4D 무한 채굴을 중심으로 통합한 설계 기준 · 시작 장면/조명 최신 결정 반영

## 1. 게임의 방향

DIG는 모바일 우선 3D 자동 채굴·탐험 게임이다. 플레이어는 드릴·조명·연구·제조 기능을 내장한, 사람이 아닌 인공지능 구체형 채굴 기계다. 개인 기억 손상은 끊기거나 서로 맞지 않는 기억 조각과 반응으로 은근히 암시하며, 기계의 정체나 과거를 단정적으로 설명하지 않는다. 작업 기록과 열차 진행 데이터는 개인 기억과 분리되어 안정적으로 유지된다.

채굴 월드는 우주의 물질과 잔해가 모이는 정체불명의 공간이다. 일반 암석·광석·금속·귀금속과 보석뿐 아니라 지구에서 만들어진 물건, 외계 물체로 보이는 물질, 생물 종을 확인할 수 없는 사체까지 발견 후보에 포함한다. 후에 밝혀지는 진실은 이렇다. 외계 물질은 미래 지구에서 개발된 물질이고, 외계 생물은 지구 생물이 우주 환경에 적응하며 진화한 후손이다. 이 설정은 모든 블록에서 물건이 반드시 나오는 뜻은 아니며, 발견 후보군과 확률표는 후속 설계 대상이다.

**플레이 흐름** · 방향 조정 → 자동 전진과 채굴 → 물품 회수 → 드릴·열차 성장 → 통로 탐색과 이동 → 연구·제작·거래 → 다음 탐험.

기존 4개 광산은 별도 클래식 모드로 유지한다. 무한 지하 프리뷰에서 실험한 기능은 4D에 채택할 때 적용 범위를 정한다. 멀티플레이는 싱글플레이 안정화 이후의 보류 설계다.

## 2. 오프닝과 조작

- **시작 장면:** 여섯 방향이 광물층 암반으로 막힌 최소 안전 공간에서 시작한다. 암전 상태에서 조명이 하나씩 켜지고 레이저 작동음이 점점 커진다. 화면에는 일반 암석 수집 수량만 표시한다. 시작 연출 동안 메뉴와 다른 버튼은 숨긴다.
- 레이저로 일반 암석 3개를 모으면 **드릴 제작** 버튼을 표시한다. 버튼을 누르면 재료를 소비해 드릴을 제작하고, 완성된 드릴은 플레이어 전방에 자동 장착된다. 이때부터 **정지** 버튼을 표시한다.
- 드릴 장착 후 플레이어 몸체가 통과할 수 있을 만큼 갱도를 넓히면 전방 자동 채굴과 자동 전진을 시작한다. 채굴 중에는 몸체를 고정하도록 체인을 자동 발사하고, 통로가 열려 전진할 때는 체인을 해제한다.
- 자동 전진이 시작되면 중력 센서가 감지한 입구 포탈 방향/위치를 메시지로 안내한다. 포탈에 가까워질수록 주변 먼지의 흐름이 빨라진다. 포탈 앞을 막은 광석을 마지막까지 채굴해 입구가 드러나면 흡인 중력이 플레이어를 끌어당긴다. 그대로 두면 포탈 안으로 들어간다. 정지 버튼의 제동 동작이나 카메라 방향을 포탈에서 돌리는 조작으로 흡인에서 벗어날 수 있다.
- **조작:** 사용자는 화면을 드래그해 시야/전방 방향만 바꾼다. 기계는 그 방향으로 자동 전진하며, 사용자는 현재 화면에 표시된 버튼만 누를 수 있다. 이동 조이스틱이나 별도 수동 이동 입력은 두지 않는다. 정지 버튼은 드릴 장착 후부터 항상 표시하고 자동 전진 및 포탈 접근 관성을 끊는다.
- **포탈 시야:** 포탈은 공간뿐 아니라 서로 다른 시간대도 연결한다. 너머로 보이는 장소와 시대는 몇 초마다 바뀐다. 목적지 좌표와 시간은 진입 전 알 수 없다.
- 오프닝 이후에도 주변광으로 공간 전체를 밝히지 않는다. 작업등이 닿는 범위만 보이고, 먼지·포탈·HUD는 지하 전체를 비추는 광원으로 쓰지 않는다. 메뉴와 강화·추가·거래·경매 버튼은 관련 조건이 갖춰질 때만 표시한다.
- 화면 회전·터치 취소·앱 비활성화 시 눌림 상태를 해제한다. 복원 중에는 자동 채굴을 멈춘다. 미로딩 구역이나 저장 실패 시의 안전 정지와 일시정지·재개 동작도 검증한다.
- **솔로 서사 대사:** 온라인 모드에서 밝혀질 시간대 간 채굴기계·거래·물질의 진실을 솔로 플레이 중 간헐적인 짧은 대사로 암시한다. 시작 인트로에서는 설명하지 않고 플레이 중 특정 발견·포탈 관측·거래 단서를 만났을 때 낮은 빈도로 표시한다. 대사는 단서를 하나씩 제시하고 외계 기계/물질/생물의 정체를 확정적으로 설명하지 않는다. 기억 파편 대사와 섞되 과도하게 반복하지 않고, 조작·채굴을 가리지 않으며, 저장 데이터와 분리한다. 재접속 대사는 별도 장면으로 유지한다.

## 3. 무한 지하와 광물

| 항목 | 통합 기준 |
| --- | --- |
| 공간 | X/Y/Z 방향으로 이어지는 지하. 0.5m 복셀, 한 변 16m 청크(32³복셀), 메시 부분 갱신 구역은 8³복셀(한 변 4m) |
| 활성·시야 | 청크 스트리밍은 플레이어 위치에 맞춰 진행. 시야는 청크 한 변 길이인 최대 16m이며, 먼지 안개가 거리에 따라 짙어져 그보다 먼 곳을 가린다. 정확한 안개 곡선은 시각 검증 후 조정 |
| 붕괴·초기화 | 플레이어와 열차가 포탈을 통해 완전히 다른 청크로 이동하면 이전 청크는 열차가 전부 빠져나온 뒤 무너지고, 그 청크의 지형·광물·아이템·통로 기록은 초기화. 청크 길이보다 긴 열차는 초기화 경계 밖에 남은 차량·화물이 소실될 수 있음 |
| 청크·광물·발견물 | 월드는 플레이어 접근에 맞춰 청크 단위로 생성한다. 청크 생성 시 광석 종류나 아이템을 미리 배정하지 않는다. 블록이 채굴되어 처음 시야에 드러나는 순간 광물 종류 또는 발견물 결과를 판정하고, 같은 세션에서 해당 블록의 결과를 유지한다. 광물 기본 확률은 암석 65%, 석탄 18%, 철 10%, 금 5%, 희귀 2%이며 깊이·지역·강화는 기본 가중치에 영향 없음. 지구 물품·외계 물체·확인 불가 생물 잔해의 후보 및 확률은 미정 |
| 세션 보존 | 같은 세션에서 청크가 유지되는 동안 굴착·광물·발견물 상태를 유지. 청크 초기화 뒤 새로 생성되면 새 결과를 판정. 재접속 시 환경·위치·통로 연결은 폐기 |
| 시설 | 채굴 월드에 매점·상점 건물을 두지 않는다. 거래는 상황별 메뉴와 소형 거래 드론으로 연결하고, 제작도 메뉴에서 진행 |

자연 공동과 플레이어가 제거한 블록을 구분한다. 한 블록의 제거, 수집 보상과 후속 마모·추가 드롭이 중복 처리되지 않게 한다. 초기 1m 캐릭터와 채굴 간격 3배는 클래식 P18 작업 브랜치의 변경이다. 4D 기계의 현재 충돌 반경은 0.32m이며 4D의 별도 채굴 속도 밸런스는 이 값과 독립적으로 검증한다.

## 4. 4차원 통로와 중력

시작 청크에는 튜토리얼을 위해 **대형 입구 포탈이 정확히 하나** 있다. 광석이 입구를 막고 있어 이를 제거한 뒤 흡인이 시작된다. 일반 청크는 소형/대형 포탈 존재를 독립 무작위 판정하므로 없거나 한 종류 또는 두 종류가 동시에 있을 수 있다. 현재 종류별 최대 한 끝을 청크에 배치하며 출현 확률 수치는 미정이다. 각 통로는 위치·시간대가 다른 출구와 한 쌍이며 목적지 정보는 알 수 없다.

- 소형 통로는 광물·소형 드론만 통과하고, 대형 통로는 플레이어 기계와 열차까지 통과한다. 먼지는 두 유형 모두 통과한다. 소형 입구 중력에 플레이어가 끌려도 기계는 aperture 면을 통과하지 못한다.
- 입구 중력은 먼지·광물·허용된 물체에 실제 가속도를 준다. 출구에서는 먼지가 계속 흘러나오며 광물/아이템은 간헐적으로 방출된다. 방출 확률은 채굴 보상 확률보다 낮게 두고 정확한 값은 미정이다.
- 중력 센서는 포탈이 감지되면 방향/위치 메시지를 제공한다. 입구에 가까워질수록 먼지 흐름이 빨라져 접근을 알린다. 입구를 가리는 광석을 제거하면 흡인이 플레이어에게 작용하며, 정지 버튼의 제동 또는 진행 방향 변경으로 이탈할 수 있다.
- 포탈 면 너머의 시각 장면은 몇 초 간격으로 바뀐다. 변화하는 장면은 위치를 확정하는 지도 정보가 아니다.
- 통과는 입구에서 출구로 한 방향만 가능하며 좌표를 즉시 바꾸는 입력은 없다. 대형 포탈에서 열차 꼬리가 출구를 완전히 벗어난 뒤 이전 청크의 임시 환경을 붕괴·초기화한다. 청크 한 변(16m)을 넘는 열차는 초기화 경계에서 후미 차량/화물이 소실될 수 있다.
- 포탈 바깥에는 포탈 중력이 없으며 센서만 가까운 중력 신호를 표시한다. 먼지·광물·아이템의 입구 유입과 출구 방출은 장식 애니메이션이 아니라 물리 이동으로 보인다.
- 포탈 쌍은 서로 다른 공간뿐 아니라 시간대도 연결한다. 너머의 장소/시대 미리보기는 몇 초마다 바뀌지만 실제 연결은 통과 세션 동안 고정된다. 미리보기는 목적지 좌표나 연도를 공개하지 않는다.

## 5. 열차와 성장

- 구체형 플레이어 기계에 드릴·작업등·연구·제조 기능이 내장된다. 뒤에 추가하는 화물칸은 열차에 연결한다. 안전한 열차 길이는 청크 한 변(16m) 이내이며, 더 길게 연결하면 청크 붕괴 때 후미 차량과 화물을 잃을 수 있다. 편성 길이 계산, 차량별 화물, 포탈 물리 통과 및 마지막 차량 통과 뒤 청크 초기화는 [열차·화물·청크 전환 상세설계](dig-4d-train-cargo-chunk-transition-detail-20261125.md)를 따른다.
- 드릴은 사용 중 확률적으로 손상될 수 있고, 수리할 때 재료를 소모한다. 손상 확률·손상량·수리 재료 수량은 미정이다.
- 기본 장비인 레이저로 드릴을 강화하고 추가 드릴을 제작해 장착한다. 추가 드릴은 병렬 채굴을 위한 장비로 설계한다. 재료·단계·동시 채굴 효과와 상한은 밸런스 결정이 남아 있다.
- 드릴 내구도가 0이고 수리 재료가 없으면 레이저로 느리게 긴급 채굴해 수리 재료를 마련한다. 레이저는 광물과 먼지를 분해해 기본 활동 에너지와 기본 재료를 얻는 기본 생존·제작 수단이다.
- 열차 진행 데이터·장비·인벤토리·연구·도감은 청크 환경 기록과 분리해 유지한다. 바닥 물품이나 청크 안에 남은 후미 차량·화물은 환경 붕괴 때 소실될 수 있다.
- 새 물품을 식별하면 연구/발견 도감(조감도 목록)에 등록한다. 메모리 손상 연출과 별개로 목록 및 작업 자료는 유지한다.
- 무한 지하 프리뷰의 칸당 40개, 최대 8칸, 엔진 5단계와 적재량 감속은 프리뷰 기준이다. 4D 열차의 용량·길이·엔진 확정값으로 사용하지 않는다.

## 6. 제작·발견물·거래

일반 암석을 기본 레이저로 가열·가공해 세라믹 장비를 제작한다. 세라믹은 다른 장비의 상위 등급 강화 재료로 폭넓게 사용한다. 모든 광물은 장비 제작과 강화 재료로 사용할 수 있다. 레이저는 광물과 먼지를 분해해 기본 활동 에너지와 기본 재료도 회수한다. 드릴 시작 제작, 확률 손상·수리, 내구도 0 긴급 채굴, 추가 드릴 및 원자적 재료 소비는 [드릴·레이저·세라믹 장비 진행 상세설계](dig-4d-equipment-materials-implementation-detail-20261125.md)를 따른다. 수량·확률·강화 단계는 미정이다.

채굴로 새로 드러나는 블록의 발견 결과에는 보석·금속·귀금속, 지구에서 만들어진 물건, 미래 지구에서 개발되어 외계 기원으로 오해되는 물질, 우주에 적응하며 진화한 지구 생물의 후손이 포함될 수 있다. 새 물품을 처음 확인할 때마다 발견 도감(조감도 목록)에 추가한다. 실제 등장 확률, 시각 표현, 회수·보관·연구 규칙은 미정이다.

소형 드론은 다른 채굴 기계와 통신·거래하기 위한 중계기다. 그 채굴 기계들은 플레이어에게 외계 존재로 보이지만, 시간대가 다른 포탈 너머에 있는 상대들이다. **매매**는 상대 기계와 즉시 사고파는 방식이며, 표시 가격은 고정되지 않고 시간·상대·시장 상황에 따라 무작위로 변한다. **경매**는 다른 시간대의 채굴 기계들이 입찰하는 비동기 거래다. 경매 기간, 입찰·정산 방식, 유찰·취소, 크레딧 및 특별 화물 승인 규칙은 후속 결정이다. 현재 통로를 지나는 소형 드론 표현은 구현됐으며 실제 거래·경매는 설계 단계다. 구체적인 시세 키, 원자적 정산, 경매 수명주기와 복원 처리는 [거래 드론 상세설계](dig-4d-trade-implementation-detail-20261125.md)를 따른다.

## 7. 저장·공유·처음부터 다시 시작

1. 4D 전용 저장에 열차 진행만 보관한다. 청크·위치·통로·월드 생성 정보는 환경과 함께 초기화한다.
2. 공유된 DIG4R1 코드는 복원 입력으로 사용할 수 있다. 입력 형식과 버전, 체크섬, 열차 스키마를 확인한다.
3. 적용 직전 현재 진행의 백업 코드를 **클립보드에 복사**한다. 자동 복사가 실패하면 수동 복사 후 확인받고, 취소되거나 저장 충돌이 있으면 현재 기록을 보존한다.
4. 백업이 확보된 뒤 현재 열차 진행을 가져온 기록으로 교체한다. Base64URL은 공유 형식이며 CRC32는 우발적 손상을 감지한다. 이메일 인증·발송을 쓰던 흐름은 클립보드 방식으로 대체됐다.
5. 처음부터 다시 시작은 확인 후 4D 열차 기록을 지운다. 클래식 광산 저장은 별도 키와 기존 호환 규칙으로 관리한다.

## 8. 클래식 광산과 온라인

**클래식.** 현재 공개된 4개 유한 광산에서 삽·곡괭이·드릴로 수동 채굴하고, 지상 캠프에서 판매·제작·강화한다. 광산 Ⅰ은 기본 개방, Ⅱ·Ⅲ은 이전 광산 굴착도로 해금하며 Ⅳ는 화산 광산이다. 자연 동굴·수정·유물·보물상자·특수 지층·도감은 안정된 발견 ID와 저장 호환을 유지한다. 광산 Ⅴ 최종 성소, 최종 유물, 엔딩 후 자유 탐험은 미완료 과제로 둔다.

**온라인.** 협력은 광물별 균등 분배와 나머지 이월, 수집량 대결은 동일 시작 조건과 서버 검증 점수, 약탈은 동의한 방에서만 허용하고 비보호 광물의 최대 20%를 이전한다. 2–4인 방, 서버 권위 정산, 접속 복구, 온라인·싱글 재화 분리를 전제로 한다. 서버·매칭·동기화·PvP 구현은 보류한다.

## 부록 · 기존 광산 설계 세부사항

### 1. 게임 개요와 플레이 흐름

DIG는 모바일 우선 1인칭 3D 채굴·탐험 게임이다. 지상 캠프에서 출발해 지하를 파고, 광물과 발견물을 수집한 뒤 캠프로 돌아와 판매·제작·장비 강화를 한다. 성장한 장비로 더 깊은 지층과 다음 광산을 탐험한다. 깊이가 늘어날수록 지층, 조명, 광물뿐 아니라 동굴, 보물상자, 유물 등 발견 대상이 달라진다.

- **굴착**은 복셀 지형의 제거와 충돌 갱신을 연결한다. 삽·곡괭이·드릴은 채굴 간격, 범위, 거리로 역할을 나눈다.
- **클래식 광산 조작**은 기존 별도 모드의 규칙이다. 이 4D 설계의 시작 인트로 이후에도 이동 조이스틱/WASD 대신 시야 방향과 상황별 화면 버튼만 사용한다.
- **지상 복귀**는 채굴로 지형이 달라져도 안전한 위치로 돌아올 수 있도록 한다. 매점과 제작소는 채굴 주기의 거점이다.
- **시각과 소리**는 깊이별 색상과 조명, 광물 발광, 도구별 타격음과 파편, 희귀 발견 연출로 채굴 결과를 전달한다.

### 2. 기존 광산 P18 작업 브랜치의 결정

| 항목 | 적용 기준 | 대화 마지막 상태 |
| --- | --- | --- |
| 캐릭터 | 높이 **1m**. 충돌 판정과 깊이 계산을 새 높이에 맞춤 | 작업 브랜치 반영 |
| 블록 | 한 변 **0.5m**. 캐릭터 높이의 절반 | 기존 크기 유지 |

| 드릴 | 기본 채굴 간격 90 → **270ms** | 작업 브랜치 반영 |

채굴 시간은 기존의 3배로 늘리고 강화 효과는 유지한다. 블록 크기 0.8m는 캐릭터 높이를 1.6m로 가정한 검토 수치였다. 시설 보호는 기존 저장 형식을 유지한다. 마지막 채굴 테스트 수정은 강화 후 기대값을 507ms에서 508ms로 정정한 것이다.

### 3. 광산과 탐험 콘텐츠

광산별 지형과 굴착 이력을 개별로 보존하고 인벤토리, 경제, 장비 성장은 광산 간 공유한다. 지상에서 해금된 광산으로 이동한다. P4 설계에서 제시된 첫 세 광산의 크기와 해금 조건은 아래와 같다. 후속 아트 설계에서 II·III의 테마 명칭이 달라진 이력이 있어 번호를 기준으로 정리했다.

| 광산 | 설계 역할 | 크기·해금 또는 상태 |
| --- | --- | --- |
| I | 초원 광산. 채굴과 성장을 익히는 시작 지역 | 16×16×12m, 기본 개방 |
| II | 협곡·수정 테마. 동굴과 희귀 수정 탐험 | 24×24×18m, I의 10% 굴착 조건 |
| III | 심층 수정·고대 유적 테마. 심층 발견물 확장 | 32×32×24m, II의 15% 굴착 조건 |
| IV | 화산 지대. 흑요석·용암·고대 기계장치 테마 | P11에서 게임 연결 및 배포 보고 |
| V | 최종 성소. 최종 유물과 엔딩의 목적지 | 설계 존재, 구현 확인 필요 |

P8에서는 일반 광물(0–3m), 작은 동굴(3–6m), 광물 군집과 상자(6–9m), 고대 유물(9–12m), 희귀 수정 동굴(12–18m), 특수 지층과 전설급 유물(18–24m)로 발견의 깊이를 단계화했다. 동굴과 수정 군집, 보물상자, 유물, 특수 지층, 발견 도감을 게임에 연결한 기록이 있다. 자연 동굴은 시드 기반으로 생성하고, 플레이어 굴착 기록과 분리해 해금 진행률·채굴 보상을 계산한다. 발견 보상은 재진입이나 저장 복원으로 중복 지급되지 않도록 한다.

### 4. 경제·제작·장비 성장

| 기본 광물 | 초기 설계 등장 깊이 | 초기 판매가 |

| 석탄 | 1m 이상 | 2G |
| 구리 | 2m 이상 | 5G |

| 금 | 6m 이상 | 25G |

깊이와 판매가는 P2의 설계 기준이다. 후속 광산에서는 광산별 분포를 적용한다. 수집한 광물은 판매해 골드를 얻거나 제작 재료로 보존한다. 석탄 연료는 굴착 속도, 구리 합금은 굴착 거리, 강철 주괴는 굴착 반경, 보석 코어는 조명 거리를 늘리는 성장 효과로 연결했다. 제작과 강화의 소모·보상은 저장 및 복원 후에도 일관돼야 한다.
