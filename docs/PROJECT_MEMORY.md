# DIG 프로젝트 메모리 / 최신 설계 기준

최종 업데이트: 2026-11-22

## 최신 우선 규칙
- 1m 캐릭터, 최소 0.5m 블록, 기존 대비 채굴 시간 3배.
- 하늘/지표면/월드 상하 경계 없이 X/Y/Z 무한 지하.
- 청크 중앙의 작은 시작 공동에서 스폰.
- 매점 건물 및 채굴 보호구역 폐기. 판매·구매·강화는 어디서나 상점 메뉴로; 제작 메뉴 유지.
- 청크 16m 정육면체 제안. 0~32m 활성, 32~64m 메모리 해제, 64~256m 기록 보존, 256m 초과 채굴·광물 기록 초기화(거리 값은 성능 검증 전 제안).
- 숨겨진 광물 종류는 청크 생성 때 사전 결정하지 않음. 채굴로 새로 노출된 고체 블록만 최초 노출 시 결정.
- 같은 청크 epoch의 광물 결과는 저장/재접속/청크 재로드 후 동일. 256m 초기화 후 epoch 변경으로 새 추첨.
- 기존 v1/v2/v3 저장 및 main 배포 보존. 신규 무한 월드는 별도 저장 버전/네임스페이스.
- 광물 무한 재생으로 인한 경제 밸런스 및 모바일 성능 검증 필요.

## 최신 조작·UI 결정 (2026-11-22)
- 기본 행동: 자동 전진, 앞의 고체 블록에 닿으면 정지 후 자동 채굴, 제거되면 자동 전진 재개.
- 사용자는 방향 조정과 메뉴 선택에 집중. 기본 화면의 수동 DIG 버튼 제거.
- 상점·가방·제작·강화·설정은 간단한 아이콘 메뉴로 제공.
- 일시정지/재개는 항상 접근 가능. 메뉴 열림·앱 비활성화 시 자동 행동 정지.
- 절벽·미로딩 청크 등 위험 구간에서 안전 정지, 기존 저장/보상 중복 방지.
- 구현 및 테스트는 아직 미완료. 상세 계약은 최신 설계 문서 7절 참고.

## 채굴 효율·랜덤 드롭 강화 권장안 (2026-11-22)
- 강화에 따라 자동 채굴 속도·범위·연속 효율을 높이고 성장 상한을 설계한다.
- 블록 광물 종류 확률과 채굴 후 추가 드롭 등급(일반/고급/희귀/영웅/전설) 확률은 별도 시스템.
- 희귀 보상 연출·도감·무료 채굴 기반 천장 시스템 검토. 유료 확률형 뽑기 및 현금 교환 제외.
- 자동/범위 채굴 중복 보상 방지, 청크 초기화 악용 및 경제 밸런스 테스트 필수.
- **이 항목은 신규 권장안으로 수치 미확정, 런타임 미구현.** 상세 설계서 9절 참조.

## 장비 내구도·수명 권장안 (2026-11-22)
- 장비별 현재/최대 내구도와 반복 수리에 따른 최대 내구도 감소. 강화 단계는 유지하되 마모가 속도·범위·효율에 영향.
- 내구도 71~100% 정상, 41~70% 90%, 11~40% 70%, 1~10% 50%, 0% 자동 채굴 정지(기본 권장값).
- 채굴 시 경도별 마모, 메뉴형 상점 수리, 사용자 설정 자동 수리/예비 장비 교체, 아이콘 아래 내구도 막대.
- 기존 저장 장비는 내구도 100%로 이행, 청크 초기화로 장비 수명 복구 불가.
- **신규 권장안이며 코드 미구현**. 상세 설계서 10절 참조.

## 상세 설계 11단계: 장비 수명·자동 채굴 경제 (2026-11-22)
- 권장 초기값: 기본 내구도 1,000, 일반 암석 1, 단단한 암석 2~5 소모.
- 수리 시 최초 최대 내구도의 1%씩 최대 내구도 감소, 최초 최대의 50%가 수명 하한. 하한 도달 후 일반 수리 불가, 장비 교체/재제작 필요.
- 장비 인스턴스별 강화와 계정 영구 성장 분리. 새 장비에 기존 장비 강화가 자동 복제되지는 않음.
- 자동 수리 기본 꺼짐, 보유 재화 하한 준수, 기본 저효율 도구로 진행 차단 방지.
- 채굴 성공·드롭·내구도·저장을 동일 이벤트 ID로 처리해 중복 지급/차감 방지.
- 경제 지표: 분당 순골드, 채굴량, 희귀 보상 획득 시간, 장비 평균 수명. **권장안이며 구현 미완료.**

## 최신 확정: 광물 깊이별 분포 폐지 (2026-11-22)
- X/Y/Z 무한 지하 전체에서 광물 종류는 **고도·깊이·지역 구분 없는 동일한 전역 확률표**로 랜덤 등장.
- 기본 공통 확률: 일반 암석 65%, 석탄 18%, 철 10%, 금 5%, 희귀 광물 2%.
- 최초 노출 시 결정, 같은 epoch에서 불변, 256m 청크 초기화 후 새 epoch 재추첨.
- 좌표는 결정적 난수의 고유 입력으로만 사용하고 광물 확률 가중치에 반영하지 않는다.
- 이전 문서의 '깊이·지역별 광물 확률', '고도에 따른 희귀도 증가' 제안은 **폐기**. 최신 상세 설계서 12절이 우선.
- 설계 확정이며 실제 코드 구현·테스트·배포 미완료.

## 상세 설계 13단계: 전역 광물·추가 드롭·채굴 효율 분리 (2026-11-22)
- 1차 광물 종류는 모든 좌표에서 65/18/10/5/2 고정. 강화·깊이로 가중치 변경 금지.
- 2차 추가 드롭은 채굴 성공 시 별도 추첨. 권장 초기안: 발생 10%, 발생 시 일반/고급/희귀/영웅/전설 60/25/10/4/1.
- 추가 드롭 전설 천장 권장: 전설 미획득 추가 드롭 500회 후 다음 추가 드롭 전설 보장. 청크 초기화로 카운터 초기화 금지.
- 장비 추가 드롭 발생 보너스 상한 20%, 1차 광물 확률 불변.
- 채굴 이벤트 하나에 블록 제거·광물/추가 보상·내구도·천장 카운터 정산. 권장 초기 수치이며 미구현.

## 상세 설계 14단계: 강화별 자동 채굴 성능 (2026-11-22)
- +0~+5 기본 채굴 시간 단축: 0/8/16/24/32/40%.
- +0~+5 최대 동시 제거 블록: 1/1/1/2/2/3개.
- +0~+5 추가 드롭 발생 확률: 10/11/12/14/17/20%. 1차 광물 확률 65/18/10/5/2 불변.
- 실제 채굴 시간은 기본 시간×3×(1−강화 단축률)÷내구도 성능 배율.
- 범위 채굴 각 블록마다 광물 보상·추가 드롭·내구도 소모. 미로딩 청크/위험 지형 자동 파괴 금지.
- **권장 초기 수치, 코드 미구현.** 상세 설계서 14절 참조.

## 상세 설계 15단계: 강화·보호석·수리 경제 (2026-11-22)
- 강화 성공률 권장: +0→1 100%, +1→2 85%, +2→3 70%, +3→4 55%, +4→5 40%.
- +3→4/+4→5 실패 시 단계 1 하락, 보호석 1개로 하락 방지(성공률 증가 없음). 낮은 단계 실패는 재료만 소모.
- 강화 실패/성공은 내구도·최대 내구도·수리 횟수에 영향 없음. 수리도 강화 단계에 영향 없음.
- 수리 골드 비용 권장식: ceil(장비 등급 기본 수리비 × 손상 비율 × (1+0.25×강화 단계)). 광물은 장비 등급 기본 수리 광물 × 손상 비율 올림.
- 수리 시 최초 최대 내구도 1% 감소, 50% 하한 도달 수리까지 허용 후 일반 수리 중단.
- 강화/수리는 거래 ID로 원자적 처리하고 재시도 재추첨·중복 소비 방지.
- **초기 권장 수치, 런타임 미구현.** 상세 설계서 15절 참조.

## 상세 설계 16단계: 제작·판매·순수익 경제 (2026-11-22)
- 광물 기본 판매가 권장: 암석 1, 석탄 4, 철 10, 금 25, 희귀 광물 100골드. 1차 광물 등장 확률 65/18/10/5/2는 X/Y/Z 전체에서 고정.
- 광물 1블록당 총판매액 기대값 5.62골드(추가 드롭/비용 제외).
- 제작 권장: 기본 도구 무료; 철 장비 300골드+철20+석탄30; 금 장비 1500골드+금25+철40; 희귀 장비 6000골드+희귀20+금50.
- 기본 수리 골드 계수: 기본0/철100/금400/희귀1500. 광물 계수: 철3/금4/희귀3. 15절 수리 산식과 연결.
- 자동 판매는 제작·수리용 보호 재고 초과분만. 자동 수리도 자원 하한 준수. 자동 제작/강화 기본 비활성화.
- 상위 장비 성장성은 시간당 순수익(판매 수익−수리/교체/강화 비용), 채굴량, 희귀 보상/시간으로 검증.
- **수치는 밸런스 검증 전 권장안, 코드 미구현.** 상세 설계서 16절 참조.

## 상세 설계 17단계: 채굴 경제 시뮬레이션 (2026-11-22)
- 장비 4종 × 강화 +0~+5 × 1/10/100시간 = 72개 기본 시나리오, 시드 100개씩 총 7,200회 실행 설계.
- 핵심 지표: 시간당 실제 제거 블록 수, 광물/추가 드롭 판매액, 수리·제작·강화 비용, 순수익, 수리/교체 횟수, 장비 평균 수명.
- 기존 기본 채굴 시간은 코드 확인 후 입력하며 임의 확정 금지. 기본 광물 전량 판매 기대값은 5.62골드/블록(추가 드롭·비용 제외).
- 모든 X/Y/Z와 높이에 동일 광물 확률 65/18/10/5/2 적용. 범위 채굴의 실제 제거 블록마다 보상·마모 1회.
- 수리 1회당 최초 최대 내구도 1% 감소, 50% 하한, 보호 재고, 청크 재생성 후 장비·천장 유지 검증.
- 시뮬레이터 결과 CSV/JSON 및 역전 밸런스 경고 설계. **아직 실행·검증·배포하지 않음**. 상세 설계서 17절 참조.
