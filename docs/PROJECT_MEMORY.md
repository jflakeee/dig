# DIG 프로젝트 메모리 / 최신 설계 기준

최종 업데이트: 2026-11-22
상태: 설계 확정 방향 정리, 구현은 별도 검증 필요

## 최신 우선 규칙
- 1m 캐릭터, 최소 0.5m 블록, 기존 대비 채굴 시간 3배.
- 하늘/지표면/월드 상하 경계 없이 X/Y/Z 무한 지하.
- 청크 중앙의 작은 시작 공동에서 스폰.
- 매점 건물 및 채굴 보호구역 폐기. 판매·구매·강화는 어디서나 상점 메뉴로; 제작 메뉴 유지.
- 청크 16m 정육면체 제안. 0~32m 활성, 32~64m 메모리 해제, 64~256m 기록 보존, 256m 초과 채굴·광물 기록 초기화(거리 값은 성능 검증 전 제안).
- 숨겨진 광물 종류는 청크 생성 때 사전 결정하지 않음. 채굴로 새로 노출된 고체 블록만 최초 노출 시 결정.
- 같은 청크 epoch의 광물 결과는 저장/재접속/청크 재로드 후 동일. 256m 초기화 후 epoch 변경으로 새 추첨.
- 기존 v1/v2/v3 저장 및 main 배포 보존. 신규 무한 월드는 별도 저장 버전/네임스페이스.
- 광물 무한 재생으로 인한 경제 밸런스 및 모바일 성능 검증 필요.

## 최신 조작·UI 결정 (2026-11-22)
- 기본 행동: 자동 전진, 앞의 고체 블록에 닿으면 정지 후 자동 채굴, 제거되면 자동 전진 재개.
- 사용자는 방향 조정과 메뉴 선택에 집중. 기본 화면의 수동 DIG 버튼 제거.
- 상점·가방·제작·강화·설정은 간단한 아이콘 메뉴로 제공.
- 일시정지/재개는 항상 접근 가능. 메뉴 열림·앱 비활성화 시 자동 행동 정지.
- 절벽·미로딩 청크 등 위험 구간에서 안전 정지, 기존 저장/보상 중복 방지.
- 구현 및 테스트는 아직 미완료. 상세 계약은 최신 설계 문서 7절 참고.
