# DIG 4D 메뉴·상황별 버튼 노출 상세설계

2026-11-25 · 조작 버튼을 최소화하고 현재 가능한 행동만 보여주는 화면 규칙

## 1. 목표와 적용 범위

플레이 중 화면에 상시 노출되는 버튼을 줄인다. 인트로의 단계별 제작 버튼은 예외로 유지한다. 정지/재개 버튼도 자동 작업 상태에 따라 필요한 순간에만 노출한다. 그 외 제작·강화·수리·거래·경매 등의 행동은 메뉴를 열었을 때 현재 조건에 맞는 항목만 보여준다.

이 게임의 직접 조작은 화면 방향 드래그와 표시된 버튼 클릭이다. 이동 조이스틱, 키보드 이동, 매점 건물, 사용 불가능한 회색 버튼의 상시 노출은 두지 않는다.

## 2. 기본 HUD와 버튼 원칙

| 상태 | 화면 버튼 |
| --- | --- |
| 시작 암전/기동 연출 | 없음 |
| 일반 암석을 모으는 인트로 | 버튼 없음 |
| 암석 3개 확보, 드릴 미제작 | 드릴 제작만 |
| 자동 채굴/전진 중 | 메뉴 + 정지 버튼 |
| 정지 상태, 안전 조건 충족 및 재개 가능 | 메뉴 + 재개 버튼 |
| 메뉴 펼침 | 메뉴 닫기 + 지금 가능한 행동 최대 2개; 별도 정지/재개 버튼 없음 |
| 기능 패널 진입 | 패널에서 필요한 확인/취소/실행 버튼만 |
| 자동 운행 중 포탈 흡인 위험 | 정지/제동 버튼 유지, 센서 경고 표시 |

자동 채굴 또는 전진이 실행 중일 때 정지 버튼을 표시한다. 자동 작업이 이미 멈췄다면 안전하게 재개할 수 있는 경우에만 재개 버튼을 표시한다. 메뉴가 열린 상태에서는 패널 버튼만 두고 정지/재개 버튼은 중복 표시하지 않는다. 진행에 필수인 상태·자원·중력 센서는 정보 표시이며 버튼으로 취급하지 않는다.

모든 버튼은 조건이 충족될 때만 표시한다. 재료·공간·장비 상태가 부족하면 해당 행동을 숨기고 메뉴 안에 부족 사유만 알려준다. 아직 해금하지 않은 기능을 비활성 버튼으로 화면에 나열하지 않는다.

## 3. 메뉴 펼침과 우선순위

메뉴 버튼을 누르면 현재 세이브·인벤토리·장비·거래 상대·위험 상태를 읽어 가능한 하위 행동을 만든다. 한 화면에는 핵심 행동을 최대 두 개만 노출한다.

하위 행동 우선순위:

1. **긴급 생존/안전:** 드릴 내구도 0의 긴급 레이저 채굴, 포탈 위험 정지/탈출
2. **즉시 진행:** 수리, 현재 드릴 강화/추가 제작처럼 다음 채굴을 직접 여는 행동
3. **현재 상황 대응:** 적재 여유 부족 시 화물칸 추가, 새 발견물 분석
4. **교류/선택 활동:** 매매 또는 경매, 연구/도감 열람

같은 우선순위 안에서는 플레이어의 현재 목표와 연결된 행동을 먼저 보여 준다. 더 많은 행동이 가능하면 메뉴 안에서 다음 묶음을 넘겨 확인하게 하되, 플레이 화면에 버튼을 모두 펼쳐놓지 않는다. 진행 조건이 바뀌면 메뉴 목록을 다시 계산한다.

## 4. 상황별 노출 규칙

| 조건 | 메뉴에서 보이는 행동 |
| --- | --- |
| 내구도 0, 수리 재료 없음 | 레이저 긴급 채굴 |
| 드릴 손상, 수리 재료 충분 | 드릴 수리 |
| 드릴 제작 재료와 빈 장비 슬롯 충족 | 드릴 추가 제작 |
| 강화 재료 충족 | 선택한 드릴 강화 |
| 발견물 미분석, 분석 조건 충족 | 물품 분석 |
| 화물칸 여유 부족 또는 새 차량 제작 조건 충족 | 화물 관리/화물칸 추가 |
| 거래 드론 통신 가능, 가격 있는 품목 존재 | 매매 |
| 거래 드론 통신 가능, 경매 등록/입찰 가능한 품목 존재 | 경매 |
| 새 도감 항목 있음 | 발견물 기록 보기 |
| 조건을 만족하는 행동 없음 | 하위 버튼 없음, 메뉴만 닫을 수 있음 |

매매와 경매가 모두 가능해도 메인 메뉴에 두 버튼을 동시에 나열하지 않는다. 현재 선택 물품이 가격을 가지면 매매를, 가격이 없는 발견물이면 경매를 우선 노출한다. 나머지는 거래 패널 안에서 전환할 수 있다.

메뉴가 열릴 때 자원이 충분했더라도 실행 직전 최신 상태를 다시 검사한다. 조건이 바뀌었으면 소비·제작을 진행하지 않고 버튼 목록과 부족 사유를 갱신한다.

## 5. 패널 동작과 운행 안전

- 메뉴를 열면 자동 채굴과 추진을 중단하고 제동한다. 위치·속도는 현재 세션에서 관리한다. 재접속과 패널 종료의 버튼 판정은 [인트로 상세설계](dig-4d-intro-implementation-detail-20261125.md)의 상태표를 따른다.
- 패널 안에서 제작·수리·거래가 진행되는 동안 이동·포탈 흡인·채굴 보상 처리를 멈춘다.
- 패널을 닫아도 자동 운행을 저절로 재개하지 않는다. 안전 조건을 충족해 재개 가능한 때에만 재개 버튼을 표시하고, 장애/저장 오류 등으로 재개할 수 없으면 이유만 안내한다.
- 포탈 흡인 중 자동 운행이 진행 중일 때 정지/제동 버튼을 즉시 노출한다. 메뉴를 열면 제동을 먼저 실행하고 패널을 표시하며, 패널 안에 중복 정지 버튼은 두지 않는다.
- 저장 오류, 복원, 청크 전환 중에는 새 거래/제작을 비활성화한다. 오류 메시지는 행동 버튼을 대신해 짧게 표시한다.
- 완료/취소 후 입력 포커스를 안전하게 반환한다. 메뉴를 빠르게 여러 번 눌러도 중복 패널이나 중복 거래 요청을 만들지 않는다.

메뉴 패널에서 물리적으로 정지하는 구체 방식과 관성 제동 시간은 운행/포탈 물리 설계 설정값에 따른다.

## 6. 터치·화면 배치

- 정지/재개와 긴급 행동은 화면 가장자리의 고정 위치에 두되 시야 중심·조준 지점·중력 경고를 가리지 않는다.
- 메뉴 하위 행동은 엄지로 누르기 쉬운 한 묶음으로 배치하고, 새 버튼이 나타날 때 기존 버튼과 겹치지 않도록 한다.
- 라벨은 동작을 직접 말한다(예: 정지, 재개, 드릴 수리, 매매). 아이콘 단독 사용은 피하고 작은 화면에서도 알아볼 수 있도록 한다.
- 버튼 누름/취소/완료 상태를 시각적으로 구분한다. 터치 취소, 화면 회전, 앱 비활성화에서는 눌림 상태를 해제한다.
- 메뉴 애니메이션은 짧고, 안전 버튼은 애니메이션 완료를 기다리지 않고 즉시 작동한다.

## 7. 상태/저장 계약

버튼 가능 여부는 단일 UI 로직에서 임의 계산하지 않고 현재 게임 상태로부터 순수하게 파생한다. 같은 상태 입력에는 같은 버튼 목록과 우선순위가 나온다. 버튼 클릭 때는 상태 revision을 검사하고 기능별 원자 트랜잭션을 호출한다.

- 재료 차감, 차량 연결, 강화/수리, 거래는 기능별 멱등 작업 ID를 가진다.
- 사용 불가 행동의 버튼을 오래된 화면 상태로 눌러도 부작용 없이 거절하고 화면을 최신 상태로 갱신한다.
- 재접속 복원, 새 게임 초기화, 청크 붕괴가 진행되는 중에는 메뉴 항목을 잠그고 안전 알림을 우선한다.
- 메뉴 개방/하위 묶음 위치는 일시 UI 상태이며, 핵심 진행 저장에 포함하지 않는다. 거래/제작 결과는 각 도메인의 저장 계약을 따른다.

## 8. 미정 항목과 완료 기준

미정: 버튼별 화면 좌표/크기, 메뉴 그룹 전환 방법, 긴급 경고 지속 시간, 화면 회전 시 재배치, 메뉴 정지 제동 곡선.

완료 기준:

- 자동 작업이 없는 기본 플레이에는 메뉴만 노출한다. 자동 채굴/전진 중에만 정지, 정지 후 안전하게 재개할 수 있을 때만 재개를 표시한다.
- 메뉴를 열었을 때 가능한 핵심 행동은 최대 두 개만 보여준다.
- 불가능한 제작/강화/거래 버튼을 상시 보여주지 않는다.
- 메뉴를 열면 운행이 정지하고 닫은 뒤 자동 재개되지 않는다.
- 자동 이동 중 포탈 흡인이 발생하면 정지/제동 버튼이 즉시 보이며, 메뉴 진입도 제동을 먼저 실행한다.
- 조건이 바뀌거나 저장 충돌이 나도 재료·화물·재화가 중복 차감되지 않는다.
- 키보드/조이스틱 이동 없이 시야 드래그와 노출된 버튼만으로 조작한다.
